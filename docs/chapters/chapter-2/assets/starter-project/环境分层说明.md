# 课程环境分层

课程不把整本书的所有软件压进一个环境。学生先恢复基础环境，进入相应专题时再使用教师提供并已经核验的专题环境。

| 环境层 | 对应内容 | 文件或记录 | 学生是否默认安装 |
| --- | --- | --- | --- |
| Python 基础环境 | 第4-13章的表格、统计、建模、聚类和基础化学信息练习 | `environment.yml` | 是 |
| R/Bioconductor 核心环境 | 第4-12章的整形、统计、绘图和 `airway`/DESeq2 案例 | `DESCRIPTION`、`renv.lock` | 需要 R 练习时恢复 |
| 第11章旧版数值复现环境 | 只用于复现教材保留的旧版 ISLP k-means 交叉表 | `outputs/2026-07-16-第11章NCI60本机复现/` 中的环境与运行记录 | 否，由教师或复核者使用 |
| 第14章 Seurat 专题环境 | 单细胞对象和最小 Seurat 案例 | `outputs/2026-07-10-第14章正文扩写完善/案例运行记录.md` | 进入专题后按教师安排 |
| 第15章专题环境 | Scanpy、Squidpy、Scirpy 等进阶案例 | `outputs/2026-07-16-第15章残余风险完善/` 中分案例锁文件 | 否，不作为第二章起步要求 |

`environment.yml` 和 `renv.lock` 是 2026-09-07 课程发布基线。它们记录本轮验证过的软件组合，不代表长期推荐版本，也不能单独保证跨操作系统得到完全相同的结果。恢复后仍要运行验收脚本，并保存实际程序路径、软件版本和输出。
