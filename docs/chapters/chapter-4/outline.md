# 第4章 Python 与 R 数据结构基础

## 本章定位

本章属于全书“三阶段人机协作边界”中的第一阶段：原生语感培养。学生在本章先亲手输入、运行、解释和调试最小代码，建立对变量、对象、索引、列名、缺失值和输出结果的直接感知。

本章不作为完整 Python 或 R 编程教程，也不追求让 AI 快速生成完整代码。Python 与 R 语法只讲到支撑医药数据表理解、基础核验和后续数据读取所需的程度。AI 在本章只用于名词解释、概念查阅、报错翻译和代码逐行解释，不用于代写完整逻辑代码、清洗脚本、统计结论或作业答案。

本章承接第2章工具环境和第3章 AI 任务说明书，后接第5章数据读取、数据字典与数据质量。学生应在进入数据读取前，先能说清代码中的对象是什么、输入从哪里来、输出保存在哪里、缺失值和列名是否被正确检查。

## 人机协作边界

### 本章允许 AI 做什么

- 解释数值、字符串、逻辑值、缺失值、列表、字典、向量、矩阵、数据框、索引和列名等概念。
- 翻译 Python/R 报错信息，帮助学生定位可能的语法、列名、路径或对象类型问题。
- 对学生已经写出的短代码进行逐行解释。
- 比较 Python 与 R 数据结构的相同点和差异。
- 根据学生给出的代码和真实列名，提出核验清单。

### 本章暂不允许 AI 做什么

- 不让 AI 生成完整循环、函数、清洗脚本或作业答案。
- 不让 AI 猜测数据表列名、样本含义、变量单位或医学解释。
- 不让 AI 把代码运行成功解释为分析结论正确。
- 不让 AI 直接给出统计判断、医学因果、临床建议或机制解释。

### 学生必须完成的原生训练

- 亲手输入并运行最小 Python/R 代码。
- 每段代码都写出输入对象、处理步骤、输出对象和改变了什么。
- 至少保留 1 条报错信息、排查过程和修正记录。
- 对 AI 的解释进行人工核验，并写入运行记录。

## 学习目标与学习证据

| 学习目标 | 学习证据 |
| --- | --- |
| 识别基础值和缺失值 | 能指出教学小表中每列的类型，并说明缺失值不能默认解释为 0、阴性或正常 |
| 区分 Python 与 R 常见数据结构 | 能把列名列表、变量解释字典、数值向量、表达矩阵和分析表匹配到合适对象 |

## 小节目录

### 4.1 数值、字符串、逻辑值与缺失值

内容要点：

- 从变量和基础值入手，说明数值、字符串、逻辑值和缺失值如何进入 Python/R。
- 区分“看起来像数字”和“可以作为数值分析”的差别，例如样本编号、药物编号不应直接当连续变量。
- 说明 Python/pandas 中常见 `None`、`NaN`，以及 R 中常见 `NA` 的使用边界。
- 强调缺失值不能默认解释为 0、阴性、正常或无效，需要回到数据字典和记录原因。
- 训练学生亲手输入最小代码，查看对象类型和缺失值判断结果。
- AI 只用于解释类型名和报错，不生成缺失值处理逻辑。

### 4.2 列表、字典、向量、矩阵与数据框

内容要点：

- 吸收 Python 基础语法教学经验，讲清列表、字典、元组和简单推导式的用途。
- 对照 R 的向量、矩阵和数据框，说明不同对象适合保存什么数据。
- 说明数据框是前半课程主要分析对象，矩阵是后续高维数据和组学章节的基础。
- 简要铺垫 AnnData 和 SingleCellExperiment 中“矩阵 + 样本/变量注释”的组织思想，不展开完整操作。
- 训练学生把列名列表、变量解释字典、数值向量、表达矩阵和分析表匹配到合适结构。
- AI 可帮助解释对象差异，但不能替学生生成完整数据处理代码。

### 4.3 样本、变量、索引与列名

内容要点：

- 把数据结构落回医药数据表：行可能是样本、记录、访视或细胞，列通常是变量。
- 说明索引和列名是代码定位数据的入口。
- 强调 AI 代码常会猜列名，因此必须先输出真实列名，再写或检查代码。
- 训练学生检查必需列、索引对齐和筛选结果。
- 学生要能解释一段筛选代码保留了哪些行、哪些列。
- 医学解释必须回到数据字典、研究设计和后续统计章节，本节只处理数据定位。

### 4.4 条件、循环与函数

内容要点：

- 对应 Python/R 基础语法中的流程控制和函数封装。
- 条件用于处理缺列、缺失值、类型错误等分支。
- 循环用于重复检查多个变量、多个文件或多个检查项，但必须逐行解释循环对象和输出。
- 函数只讲最小封装，例如检查列名、统计缺失值、返回核验结果。
- 本节严禁让 AI 直接生成完整逻辑代码。AI 只能解释学生已写代码、翻译报错或提出核验问题。
- 学生要能说明函数输入、返回值和副作用，避免只看代码是否运行。

### 4.5 脚本化分析与运行记录

内容要点：

- 对应模块导入、文件输入输出和早期调试训练。
- 区分交互式尝试和脚本化分析，不展开复杂文件读写。
- 说明脚本、模块导入、输入数据、输出结果和运行记录的基本关系。
- 学生需保存代码文件、运行日期、输入数据、输出结果、报错和人工修正。
- AI 协作记录要包含提示词、AI 解释、人工核验、修改后代码和仍需确认项。
- 为第5章 CSV/Excel 读取、路径、原始数据保护和清洗记录做铺垫。
