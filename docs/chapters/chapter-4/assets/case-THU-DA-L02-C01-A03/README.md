# 五行猜糖豆记录：数据对象练习

素材ID：THU-DA-L02-C01-A03。用于第4章；第1、3章引用同一表帮助读懂观察单位和任务边界。

原情境来自清华《数据分析引论》第2讲猜糖豆活动：公布1814克净重，展示罐子并收集估计，随后换成透明沙拉碗展示，再次收集回答（约11:48-15:44）。本章正文4.1取“改变展示方式、再次估计”的情境，按记录设计目标重新编排，省去与数据结构无关的现场细节。原活动依据是课程讲稿和相应字幕；五行表由本书另编。

本表由教材编写过程独立构造，**不是课程原始记录，也不是对其数据的恢复**。保留的是多轮回答这一问题结构；五条记录、三个编号、估计值、缺失及字段设计均属新编，不声称与原问卷结构相同。没有实际参与者，没有给定糖豆真实总数，不用于证明群体智慧或估计准确性。

## 字典

| 字段 | 类型 | 含义与单位 | 规则 |
| --- | --- | --- | --- |
| record_id | 文本 | 一次回答的记录号 | 本表唯一，不是人数 |
| participant_id | 文本 | 虚构参与者编号 | 同人可有多轮回答 |
| round | 整数 | 回答轮次 | 1或2 |
| estimate_grains | 数值 | 估计糖豆数量，粒 | 空白是未记录，不是0 |

5条记录、3个编号；只有第3行缺失估计值。各轮是否互相交流未作设定，因此不能据此推断独立性或学习效果。

## 运行

在本目录执行：

```powershell
python python/objects.py
Rscript r/objects.R
```

Python需要pandas；R仅用基础包。两个脚本均读取data/guesses.csv，不改输入，分别写入results/python和results/r。筛选规则为“非缺失且估计值≥950粒”，保留原始记录顺序。与expected中的人工核对表比较，整数与记录ID须完全一致。无随机过程。

## 解释边界

筛选得到的是满足条件的记录，不是“估计正确的人”。重复作答保留关联标识；记录数不能充当独立参与者数。
