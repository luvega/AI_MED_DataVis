# Lolamicin练习数据与来源

研究者在E. coli BW25113培养物中设置未处理对照、Lolamicin 4×MIC和环丙沙星4×MIC处理，在不同时间取样，稀释、涂布和培养计数后换算CFU/mL。CFU/mL表示每毫升中的菌落形成单位数，依赖相应培养与测量条件。

论文：[A Gram-negative-selective antibiotic that spares the gut microbiome](https://www.nature.com/articles/s41586-024-07502-0)，Muñoz等，Nature 630, 429-436 (2024)，DOI：10.1038/s41586-024-07502-0。

数据定位：[出版方Source Data工作簿](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-024-07502-0/MediaObjects/41586_2024_7502_MOESM9_ESM.xlsx)，`ED Fig. 3a`，响应单元格B2:J5。这里提供的是上述数值及定位字段整理成的CSV，未重新测量，也不是逐平板计数日志。

| 文件 | 内容 |
|---|---|
| data/raw/lolamicin_2_8h.csv | 同一Lolamicin处理的2小时和8小时，共6条记录 |
| data/raw/lolamicin_ecoli_timekill.csv | 3处理×4时间×3重复，共36条记录 |
| data/teaching/constructed_missing.csv | 独立构造的3行练习数据，只演示6000、空白与0；不属于论文 |

| 字段 | 含义 |
|---|---|
| treatment | 作者源表的处理名称；两种药物的4×MIC分别相对于各自MIC，不表示质量浓度相同 |
| time_h | 时间，小时；本表只有1、2、4、8小时，没有0小时实测行 |
| repeat_column_index | 相同处理块内原表的列序号，用于定位；不等于完整样本身份 |
| value | CFU/mL数值 |
| unit | 单位CFU/mL |
| replicate_definition | 作者图注所述的生物学三重复 |
| source_sheet | 作者工作表名称ED Fig. 3a |
| source_cell | value对应的作者单元格 |

2小时子集来自E3/F3/G3，数值6000、18000、51000；8小时子集来自E5/F5/G5，数值200、5500、100。源表较大的读数仍保留，不能仅因与其他值相差较大就删除。

36行是测量记录数，不应报告成36个独立实验。没有根据重复列序号补出跨时间配对关系，也没有把方法中的起始浓度填成0小时记录。

作者Extended Data Fig. 3以均值±SEM展示。练习汇总表另列样本SD，首次教学图只画原始点与均值；二者用途在课堂中分别解释。由本练习的计算不直接推断临床疗效、总体药物优劣或机制。
