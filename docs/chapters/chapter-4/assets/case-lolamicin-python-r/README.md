# Lolamicin：从三条记录到Python与R对照

本练习配合第4章4.5的药学练习使用。数据取自Muñoz等发表于Nature的研究，作者源表为ED Fig. 3a；具体字段、来源单元格和使用边界见[数据与来源](数据与来源.md)。这里保留核验后的36行记录及六行子集，原始数值不作改动。构造的缺失示例单独位于`data/teaching/`。

| 课次 | 怎样使用 |
|---|---|
| 第四课 | 按正文亲手输入三值计算、修改报错，再自行创建`scripts/mean_cfu.py`；换成8小时的完整三条记录重跑。 |
| 第五课 | 运行并修改`scripts/lesson05_read_table.py`，读六行表、按时间筛选并核对来源。 |
| 第六课 | 用`scripts/lesson06_summary.py`汇总36行；用`scripts/lesson06_compare.R`运行并修改熟悉的六行任务；教师展示`scripts/lesson06_plot.py`生成的原始点与均值图。 |
| 第七课 | 用`scripts/lesson07_r_points.R`继续读取第六课R导出的结果作图；随已有代码阅读循环。 |

复制整个目录到自己的课程工作区，在包含`data`与`scripts`的目录下运行。软件准备和具体命令见[课前准备与运行说明](课前准备与运行说明.md)。`outputs/`保存本人实际运行结果；修改目标时间后重新运行会更新相同名称的结果文件。

2小时应选中E3/F3/G3，数值为6000、18000、51000，均值25000 CFU/mL；8小时应选中E5/F5/G5，数值为200、5500、100，均值约1933.33 CFU/mL。先核对来源记录和数值，再比较均值，不能只看屏幕小数位是否相同。

均值在原始CFU/mL尺度上计算。第六课教学图展示原始点与均值，不画误差线；作者图注使用SEM，教学汇总表中的`sd_cfu`是样本SD。二者在第七课继续辨析。重复列序号不提供跨时间配对身份，图中只连接各时间均值。
