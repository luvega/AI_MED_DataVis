# 第四至第六课练习目录：准备与运行

本目录用于课堂实际输入和运行。第四课只需要Python自带功能；第五课增加pandas，第六课准备R与matplotlib。软件安装在相应课前完成。

## 第四课前确认入口

教师给出适用于本人电脑的一条Python启动命令。在系统终端运行它，看到`>>>`后输入`2 + 2`，确认显示4，再输入`exit()`退出。这里不要求使用某一种编辑器或终端界面。

本说明以`python`表示已经验证过的入口。如果原项目使用`.venv`，Windows下可能是`.\.venv\Scripts\python.exe`，macOS/Linux下可能是`./.venv/bin/python`；也可能使用已经配置好的`python3`。请固定使用教师帮助核验的那一个入口，不轮流猜命令。`>>>`由Python显示，不是需要输入的代码。

找不到命令或启动失败时，把实际提示交给教师或助教。不要把`pip install`、运行文件的命令或系统目录命令输入到`>>>`后。这个提示符后接收的是Python语句。

## 练习目录

```text
学生练习/
  data/
    raw/                 已核对的作者数值及来源字段，只读
    teaching/            明确标注的教学构造数据
  scripts/               第五至第七课配套程序；第四课在这里新建mean_cfu.py
  outputs/               本人运行产生的结果
```

把整个练习目录放在自己的课程工作区，保留内部结构。终端当前目录应为这个目录，能看到`data`和`scripts`。教师会带你确认一次；不要因为程序文件在`scripts`里，就先进入`scripts`再运行本说明中的命令。

第四课新建并手动输入`scripts/mean_cfu.py`。文件保存为UTF-8纯文本，扩展名是`.py`，检查没有误存成`.py.txt`。代码中不带`>>>`、`...`提示符，也不把运行结果抄进代码。若正在Python交互模式，先输入`exit()`，再在系统终端运行：

```text
python scripts/mean_cfu.py
```

每次改动后保存，再运行，查看这一次的输出。脚本运行结束后重新出现系统提示符属于正常情况。

## 第五、第六课前的准备

教师提前在同一个Python环境中确认pandas可用，第六课作图时再确认matplotlib。学生第一次使用`import`时会在课上解释其作用；安装软件包与在代码中导入软件包是两项不同操作。

从练习目录运行配套文件：

```text
python scripts/lesson05_read_table.py
python scripts/lesson06_summary.py
python scripts/lesson06_plot.py
```

第五课的主要修改位于`target_time = 8`。将8改为2，保存并运行，核对选中记录，再改回8。程序会更新`outputs/python_selected.csv`，文件名保持相同，表内的时间列说明本次结果属于哪个时间。

第六课前，教师帮助确认R与Rscript的入口。R用于交互输入，Rscript用于运行保存的R文件。进入R后可先输入`mean(c(6000, 18000, 51000))`核对25000，退出时输入`q(save = "no")`，不保存会话对象。课堂重新建立需要的对象。

第六课保存并运行配套R脚本：

```text
Rscript --vanilla scripts/lesson06_compare.R
```

若Rscript没有配置为直接可用命令，使用教师给出的可执行文件入口；不能据此认为R代码本身出错。Windows PowerShell中，带空格的可执行文件完整路径需要由教师写成可直接使用的命令，不让学生在本课同时学习路径转义。

`--vanilla`使这次脚本运行不读取先前保存的R会话和个人启动设置，便于检查脚本是否完整。第六课R脚本也用`target_time <- 8`控制时间，导出`outputs/r_selected.csv`。第七课继续运行：

```text
Rscript --vanilla scripts/lesson07_r_points.R
```

该R图读取上一条命令生成的结果。修改目标时间后，应先重新运行第六课R脚本，再作图。

## 数据与输出怎样区分

`data/raw/lolamicin_2_8h.csv`有6行、8列；`data/raw/lolamicin_ecoli_timekill.csv`有36行、8列。数据说明见[数据与来源](数据与来源.md)。第四课直接使用教师给出的三条值，第五课才读取文件。

`data/teaching/constructed_missing.csv`是完全独立的教学构造表，用于观察空白和0的差别，不能作为论文的实验记录引用。

本目录中的程序是练习材料。实际输出在本人运行后产生，文档里的预期值仅用于核对。教师的运行记录保存在教师材料目录，不能替代自己的运行证据。

## 常见卡点

| 现象 | 先检查 |
|---|---|
| 启动命令找不到 | 是否使用了课前确认过的解释器入口 |
| 在`>>>`后运行`python scripts/...`时报错 | 先用`exit()`退出Python，再输入系统命令 |
| 改了代码却结果没变 | 是否保存、运行的是否是这一份文件；交互模式下是否重做了计算行 |
| 找不到CSV | 当前目录是否能看到data与scripts；路径拼写是否一致 |
| `ModuleNotFoundError` | 是否在已安装该包的同一个Python环境运行；交由课前环境支持处理 |
| 出现`...` | 当前语句可能尚未输入完整，补齐括号或用Ctrl+C取消当前输入 |
| Python与R小数位不同 | 先核对来源记录与数值，不只比显示字符 |

学生设备是否完成以上准备，以实际运行记录为准。本说明本身不代表设备已经通过验收。
