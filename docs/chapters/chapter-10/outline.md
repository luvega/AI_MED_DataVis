# 第10章 模型评估、特征选择与可解释性

## 本章定位

第10章位于第三篇“图表表达、统计推断与基础建模”的收束位置，承接第9章相关、回归与分类模型，并为第11章高维矩阵和后续组学分析做准备。本章不把重点放在堆叠算法名称，也不把模型指标写成医学结论。重点是让学生理解：训练集表现不等于测试集表现，交叉验证和 bootstrap 用于估计模型或参数的不稳定性，特征选择和正则化要放在验证流程内完成，树模型和变量重要性需要谨慎解释，生存分析必须处理时间和删失，模型报告要写清数据来源、评估范围和解释边界。

本章仍处在 Prompt Coding 阶段。AI 可以辅助生成局部 Python 和 R 代码、解释报错、整理指标表、画交叉验证曲线或变量重要性图，但不能替学生决定训练/测试划分、泄漏风险、特征筛选规则、医学变量含义、阈值选择和生物医学解释。

本章面向药学本科生和研究生，默认学生已经理解数据读取、清洗、统计推断、基础回归和分类指标，但尚不熟悉模型泛化、验证设计和可解释性语言。正文应围绕“是什么、为什么、怎么检查”展开，少讲公式推导，多讲验证流程、常见误区和报告规范。

## 学习目标

1. 学生能解释训练集、验证集、测试集和数据泄漏的含义，并能指出常见泄漏来源。
2. 学生能说明交叉验证和 bootstrap 的用途、基本流程和局限，理解它们不能修复错误数据和错误研究设计。
3. 学生能区分过滤法、包装法、嵌入法和正则化的入门思路，并能说明特征选择必须纳入验证流程。
4. 学生能解释决策树、随机森林、boosting 和变量重要性的基本含义，知道变量重要性不等于因果或机制。
5. 学生能解释生存分析中的时间到事件、删失、Kaplan-Meier 曲线、log-rank 检验和 Cox 模型的入门含义。
6. 学生能写出不越界的模型评估与解释报告，包含数据划分、模型、参数、指标、特征处理、解释图、限制和需补证据。
7. 学生能阅读并核验 Python 与 R 的入门代码，说明两种语言输出的变量、模型和指标是否一致。

## 逻辑压力测试

| 压力问题 | 本章处理 |
| --- | --- |
| 训练集 AUC 很高，能否说明模型可靠？ | 不能。先看是否有独立测试、交叉验证、泄漏检查、类别比例和阈值说明。 |
| 交叉验证平均结果不错，能否直接写成临床可用？ | 不能。交叉验证是内部评估，不替代外部验证和临床研究设计。 |
| 先用全部数据筛出重要特征，再做交叉验证可以吗？ | 不可以。特征筛选必须放在每个训练 fold 内，否则验证集信息已经进入模型。 |
| 随机森林变量重要性最高的变量是不是病因？ | 不是。变量重要性只说明模型预测贡献，可能受相关变量、尺度、类别数和抽样波动影响。 |
| Kaplan-Meier 曲线两组分开，能否说明某处理延长生存？ | 不能直接写。还要看研究设计、分组定义、删失、风险人数、统计方法和混杂因素。 |
| SHAP 图显示某变量推高预测概率，能否写成机制解释？ | 不能。SHAP 解释模型输出，不证明生物机制或临床因果。 |

## 小节目录

### 10.1 训练集、测试集与数据泄漏

内容要点：

- 首次解释训练集、验证集和测试集：训练集用于拟合模型，验证集用于调参或选择模型，测试集用于最终评估。测试集不能参与模型选择。
- 说明为什么训练集表现常常偏乐观：模型已经见过训练数据，尤其在样本少、特征多、模型灵活时更容易过拟合。
- 首次解释数据泄漏（data leakage）：模型训练过程中使用了未来信息、测试集信息、结局衍生变量或不该提前知道的信息。
- 列出医药数据常见泄漏：先全数据标准化再切分，先全数据筛特征再交叉验证，同一患者多次记录被切到不同集合，把诊断后变量用于诊断前预测，使用由结局计算得到的字段。
- 说明划分策略要看数据结构：普通独立样本可随机划分；病例-对照或类别不平衡任务需分层；时间预测任务要保留时间顺序；同一患者或同一批次数据需成组划分。
- Python 和 R 示例都应展示训练/测试切分、随机种子、分层或分组思路，并提醒不在测试集上调参。
- 学习证据：学生能审阅一段建模流程，标出训练/测试混用、全数据预处理和重复样本泄漏风险。
- 解释边界：独立测试集表现仍只代表当前测试来源，不等于外部临床泛化能力。

### 10.2 交叉验证与 bootstrap

内容要点：

- 首次解释重采样（resampling）：反复用不同数据子集拟合或评估模型，用来估计性能波动或参数不确定性。
- 解释 k 折交叉验证：把训练数据分成 k 份，轮流用一份验证、其余训练，最后汇总性能。分类任务常用分层 k 折保持类别比例。
- 说明交叉验证的两类用途：估计测试误差和选择模型复杂度或调参。二者都要限定在训练数据内部。
- 解释交叉验证中的预处理规则：标准化、缺失填补、特征选择和降维必须在每个训练 fold 内拟合，再应用到对应验证 fold。
- 首次解释 bootstrap：从原始数据中有放回抽样，重复计算统计量或模型结果，用于估计标准误、置信区间或稳定性。
- 说明 bootstrap 的边界：它模拟抽样波动，不会创造新的独立受试者，也不能修复偏倚、泄漏、错误标注或非代表性样本。
- Python 和 R 示例都应展示 k 折交叉验证和一个 bootstrap 区间估计的最小流程。
- 学习证据：学生能画出 k 折交叉验证流程，并解释为什么“先筛特征再交叉验证”会夸大模型表现。
- 解释边界：交叉验证和 bootstrap 都是内部评估工具，不能替代外部验证或临床研究设计。

### 10.3 特征选择与正则化

内容要点：

- 首次解释特征（feature）：模型输入变量。本教材中可以是临床指标、药物属性、基因表达量、图像衍生指标或文本编码结果。
- 说明特征选择的目的：减少噪声、降低维度、提高可解释性或改善泛化表现。特征少不必然更正确，特征多也不必然更全面。
- 区分三类入门方法：过滤法独立于模型先给特征打分；包装法用模型性能反复搜索特征子集；嵌入法在模型拟合过程中完成选择。
- 解释高维小样本风险：特征数量远多于样本数时，训练集上容易找到偶然相关的变量，必须用严格验证控制选择偏倚。
- 首次解释正则化（regularization）：在模型拟合时加入惩罚，限制模型复杂度。ridge 倾向于缩小系数，lasso 可以把部分系数压到零。
- 说明 lambda 等调参必须通过训练集内部验证完成，不能为了测试集表现反复调整。
- Python 和 R 示例都应展示 lasso 或 ridge 的最小流程，并记录特征处理和调参范围。
- 学习证据：学生能解释过滤法、lasso 和随机森林变量重要性的差异，并指出每种方法的报告边界。
- 解释边界：被选中的特征只能说明在当前数据和模型中有预测或区分贡献，不等于病因、机制、诊断标志物或治疗靶点。

### 10.4 树模型与变量重要性

内容要点：

- 首次解释决策树（decision tree）：用一系列变量切分规则形成预测路径，适合展示非线性和交互的入门直觉。
- 说明单棵树的优点和风险：图形直观、便于解释，但对数据扰动敏感，容易过拟合。
- 解释 bagging、随机森林和 boosting 的入门区别：bagging 用 bootstrap 生成多棵树并平均或投票；随机森林在每次切分时随机选择候选变量；boosting 顺序训练多个弱树，逐步改进错误。
- 首次解释 OOB（out-of-bag）误差：bagging 或随机森林中未进入某棵树训练样本的记录可用于估计误差。OOB 是内部估计，不等于外部测试。
- 解释变量重要性（variable importance）：衡量变量对模型预测贡献的指标，常见口径包括分裂带来的 impurity 降低或置换后性能下降。
- 说明变量重要性的风险：受变量尺度、类别数、相关变量、抽样波动和模型设置影响；多个高度相关变量可能分摊重要性。
- Python 和 R 示例都应展示一棵浅树或随机森林、测试集指标和变量重要性图。
- 学习证据：学生能用树模型结果写出“预测贡献”而不是“致病原因”的解释，并列出至少两个变量重要性偏倚来源。
- 解释边界：树模型表现好不等于可解释性充分；变量重要性图不能直接支持机制解释或临床行动。

### 10.5 生存分析入门

内容要点：

- 首次解释生存分析（survival analysis）：分析从起点到事件发生时间的数据。事件可为死亡、复发、缓解、出版、设备失效等，本教材涉及医学场景时需明确事件定义。
- 首次解释删失（censoring）：到观察结束时尚未发生事件，或失访导致真实事件时间未知。删失不是缺失值，不能简单删除。
- 说明生存数据的基本字段：个体 ID、起始时间、随访时间或终止时间、事件状态、分组变量和协变量。
- 解释 Kaplan-Meier 曲线：用阶梯曲线估计随时间变化的未发生事件概率；图注要写清时间单位、事件定义、删失和风险人数。
- 解释 log-rank 检验：用于比较两组或多组生存曲线差异的入门方法，但不调整多个协变量。
- 解释 Cox 比例风险模型：用于分析协变量与风险函数的关系；需要检查比例风险假设，hazard ratio 不能写成个体生存概率。
- 本章只讲入门读图和报告边界，不展开复杂建模推导。
- Python 和 R 示例都应展示 Kaplan-Meier 曲线的最小代码；Cox 模型只做结果字段识别和边界提醒。
- 学习证据：学生能读懂一张 Kaplan-Meier 曲线的横轴、纵轴、删失标记和风险人数表，并写出克制图注。
- 解释边界：入门生存分析不支持直接给患者预后判断或治疗建议；若缺少研究设计、随访定义和外部验证，应标 `需补证据`。

### 10.6 模型可解释性与报告规范

内容要点：

- 区分可解释性（interpretability）和可解释工具：简单模型、系数、树结构、变量重要性、局部解释图都只是帮助理解模型行为的方式，不自动提供因果证据。
- 说明全局解释和局部解释：全局解释概括模型整体依赖哪些变量，局部解释说明某个样本的预测受哪些变量影响。
- 介绍报告中可出现的解释材料：模型公式或算法名、特征处理、系数或 OR/HR、变量重要性、部分依赖或 SHAP 等局部解释图。SHAP 只作为可选解释工具提及；正文主线放在系数、变量重要性和报告边界。
- 模型评估报告最低字段：数据来源、分析表版本、样本单位、划分策略、特征处理、模型与参数、验证方式、指标、置信区间或性能波动、解释图、限制、AI 协作记录和需补证据。
- 说明医学报告边界：模型用于预测或区分，不等于诊断、治疗、机制或因果。若要进入临床应用，还需外部验证、校准、决策曲线、伦理审查和专业指南支持。
- 给出结果表达阶梯：当前数据观察；模型内部验证表现；独立测试表现；外部验证表现；临床应用证据。正文按证据等级选择动词。
- Python 与 R 代码输出的模型报告字段应保持一致，便于学生核对不同工具结果。
- 学习证据：学生能审阅一段 AI 生成模型解释，指出过度推断、训练/测试混用、指标缺失和医学越界。
- 解释边界：可解释性工具解释的是模型，不是生物系统本身。

| Kaplan-Meier 曲线 | 展示时间到事件数据 | 时间单位、事件定义、删失、风险人数、分组 | 不写个体预后或疗效 |
| 模型报告分层表 | 区分观察、模型表现、解释和医学边界 | 证据来源、可写表述、需补证据 | 不把模型解释写成医学事实 |

## AI 协作点

| 场景 | 可让 AI 做什么 | 学生必须核验什么 |
| --- | --- | --- |
| 数据划分 | 生成 Python 与 R 的训练/测试切分代码 | 结局比例、分层变量、同一患者重复样本、时间顺序、泄漏风险 |
| 指标计算 | 整理准确率、AUC、灵敏度、特异度、MSE、MAE 等代码 | 指标适用任务、正类定义、数据集范围、阈值和置信区间 |
| 交叉验证 | 生成 k 折或分层 k 折流程 | 预处理、标准化、特征选择是否在每个 fold 内完成 |
| bootstrap | 生成重抽样和区间估计代码 | 抽样单位是否正确，是否把重复测量当独立样本 |
| 特征选择 | 生成候选筛选流程和结果表 | 是否只用训练集筛选，是否记录筛选规则，是否过度解释变量 |
| 树模型 | 生成决策树或随机森林代码和变量重要性图 | 参数、随机种子、过拟合、OOB/测试指标、解释边界 |
| 生存分析 | 生成 Kaplan-Meier 或 Cox 入门代码 | 时间单位、事件编码、删失定义、比例风险假设和医学解释 |
| 报告润色 | 改写过强表述，补充限制 | 是否新增样本量、机制、疗效、诊断或临床建议 |

## 需补证据

| 位置 | 缺口 | 处理方式 |
| --- | --- | --- |
| 正式课堂数据集 | 尚未指定第10章统一案例数据文件 | 正文使用教学模拟字段，并明确不代表真实医学结论 |
| 生存分析案例 | 尚未指定真实随访数据和事件定义 | 正文只做结构入门，所有医学解释标 `需补证据` |
| SHAP 等解释工具 | 当前材料未充分支撑工具细节和可靠性讨论 | 可作为可选扩展或报告字段，正文不把 SHAP 图作为唯一解释依据 |
| 外部验证 | 未提供外部队列或独立中心数据 | 所有模型表现限定为教学数据或内部验证范围 |
| 第9章状态 | 第9章大纲仍处待确认状态 | 第10章按教材大纲独立成章，正文写作时避免重复第9章基础模型内容 |
