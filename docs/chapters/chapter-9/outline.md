# 第9章 相关、回归与分类模型

## 本章定位

第9章位于第三篇“图表表达、统计推断与基础建模”的后半部分，承接第8章“统计推断与组间比较”，并为第10章“模型评估、特征选择与可解释性”做准备。本章不把模型讲成公式堆叠，也不把代码运行成功当作模型可靠。重点是让学生理解：相关描述两个变量共同变化，线性回归用模型估计连续结局，逻辑回归处理二分类结局，混淆矩阵和 ROC 帮助观察分类错误与阈值影响，医学模型报告必须写清数据、阈值、指标和风险边界。

本章面向药学本科生和研究生，默认学生已学过数据读取、清洗、描述统计、图表规范、P 值、置信区间和效应量，但尚不熟悉建模语言。正文应围绕“先画图和检查数据，再拟合模型；先解释系数和错误类型，再谈医学含义；先记录阈值和验证范围，再报告模型表现”展开。

本章处于第二阶段 Prompt Coding。学生可以让 AI 辅助生成局部 Python 和 R 模型代码、解释报错、生成诊断图和整理模型报告，但必须亲自核验变量类型、缺失处理、异常值、样本独立性、结局定义、阈值选择、分类指标和医学解释边界。

## 学习目标与学习证据

1. 学生能解释相关分析的用途和边界，能用散点图、相关系数和异常值检查描述两个连续变量的关系。学习证据是提交一张 `dose` 与 `ALT` 的散点图、相关系数表和不含因果越界的说明。
2. 学生能拟合一个入门线性回归模型，解释截距、斜率、残差、置信区间和 R²，并能识别明显的非线性、异方差和异常点风险。学习证据是提交 `ALT ~ dose` 或 `ALT ~ age + dose` 的系数表、残差图和模型边界说明。
3. 学生能说明分类问题与连续结局建模的区别，能解释逻辑回归输出的是预测概率和分类依据，而不是直接的诊断结论。学习证据是提交正类定义、类别编码和阈值说明。
4. 学生能根据混淆矩阵计算并解释准确率、灵敏度、特异度、阳性预测值、阴性预测值和 ROC/AUC 的基本含义。学习证据是手算一个混淆矩阵中的核心指标，并说明漏判和误判。
5. 学生能写出一段不越界的模型报告，包含数据来源、结局定义、预测变量、模型方法、阈值、评价指标、诊断检查、限制和需补证据。

## 小节目录

### 9.1 相关分析与散点图

内容要点：

- 首次解释相关（correlation）：两个变量共同变化的统计关系。本教材中主要用于探索两个连续变量之间是否存在近似线性或单调关系。
- 说明散点图是相关分析前的必要检查：先看趋势、异常点、聚类、分层、非线性和测量范围，再计算相关系数。
- 区分 Pearson 相关和 Spearman 相关的入门用途：Pearson 更关注线性关系，Spearman 更关注单调排序关系；选择前需要看图和数据类型。
- 说明相关系数的方向和大小：正相关、负相关、接近 0 的关系；强调相关大小要结合样本量、变量范围和异常值解释。
- 说明相关分析报告最低字段：变量名称、单位、样本量、缺失处理、相关方法、相关系数、置信区间或 P 值、图表说明和解释边界。
- Python 和 R 代码都应显示：数据检查、散点图、相关系数计算和结果说明。
- 学习证据：学生能为 `dose` 与 `ALT` 或 `AST` 的关系绘制散点图，计算相关系数，并写出不含因果越界的解释。
- 解释边界：相关不等于因果；共同变化可能来自混杂因素、分组结构、批次差异、测量范围限制或异常点。

### 9.2 线性回归与模型诊断

内容要点：

- 首次解释线性回归（linear regression）：用一个或多个自变量估计连续结局变量的模型。本章重点讲简单线性回归和少量协变量的入门模型。
- 解释截距和斜率：截距是自变量为 0 时模型估计值，是否有实际含义取决于变量范围；斜率表示自变量增加一个单位时结局的平均变化。
- 解释拟合值、残差和残差图：残差是观察值与模型拟合值之差；残差图用于检查模型是否存在明显非线性、异方差、异常点或相关误差。
- 解释 R² 的入门含义：模型解释的结局变异比例；R² 高不等于模型有医学因果意义，R² 低也不一定说明关系完全无用。
- 说明线性回归报告最低字段：结局变量、自变量、样本量、系数、标准误或置信区间、P 值、R²、残差诊断和限制。
- Python 和 R 代码都应显示：建模前散点图、模型拟合、系数表、残差图、模型报告字段整理。
- 学习证据：学生能用教学模拟数据拟合 `ALT ~ dose` 或 `ALT ~ age + dose`，并解释斜率、置信区间和残差图。
- 解释边界：回归系数描述模型中的关联或预测关系；没有设计、混杂控制和外部验证时，不写剂量导致指标变化、机制解释或临床建议。

### 9.3 分类问题与逻辑回归

内容要点：

- 首次解释分类问题（classification）：模型目标是把样本分到离散类别。本章以二分类为主，例如 `response` 的 0/1 或 no/yes。
- 首次解释逻辑回归（logistic regression）：用于估计二分类结局发生概率的模型。正文只讲概率、阈值和系数方向的入门含义，不深讲数学推导。
- 区分线性回归和逻辑回归：线性回归适合连续结局，逻辑回归适合二分类结局；不能把二分类结局简单当连续变量处理。
- 解释阳性定义和类别编码：正类必须在建模前写清，0/1、no/yes、control/case 的编码会影响系数方向和混淆矩阵解释。
- 说明概率到类别需要阈值：常见 0.5 阈值只是教学起点，医学任务中阈值需结合漏判和误判风险。
- 解释 odds ratio 的入门边界：可作为“方向和相对变化”的补充，但本章不做公式推导，也不把 OR 写成风险比或因果效应。
- 逻辑回归报告最低字段：结局定义、正类定义、预测变量、样本量、类别比例、模型方法、预测概率、阈值、评价指标和解释边界。
- Python 和 R 代码都应显示：类别编码、逻辑回归拟合、预测概率、阈值分类和结果表。
- 学习证据：学生能用 `age`、`ALT`、`AST` 等变量预测教学模拟 `response`，并说明正类、阈值和预测概率含义。
- 解释边界：逻辑回归输出是模型估计概率或关联强度，不等于诊断结果、治疗建议或病因机制。

### 9.4 混淆矩阵、灵敏度、特异度与 ROC

内容要点：

- 首次解释混淆矩阵（confusion matrix）：用真实类别和预测类别交叉展示分类结果，帮助识别正确分类、假阳性和假阴性。
- 统一 TP、FP、TN、FN 的写法：TP 是真实阳性且预测阳性，FP 是真实阴性但预测阳性，TN 是真实阴性且预测阴性，FN 是真实阳性但预测阴性。
- 解释准确率、灵敏度、特异度、阳性预测值和阴性预测值：每个指标的分母不同，不能混用。
- 强调类别不平衡风险：准确率可能掩盖少数类错误，医药分类任务不能只报告准确率。
- 首次解释 ROC 曲线和 AUC：ROC 展示不同阈值下灵敏度和 1-特异度的关系，AUC 概括区分能力。
- 说明 ROC 与阈值选择的关系：AUC 评估排序或区分能力，具体阈值仍需结合任务风险、样本来源和验证数据。
- Python 和 R 代码都应显示：预测概率、阈值分类、混淆矩阵、指标计算、ROC 曲线和图注。
- 学习证据：学生能根据一个混淆矩阵手算灵敏度和特异度，并解释某个阈值下漏判和误判的含义。
- 解释边界：ROC/AUC 不能单独证明模型可以临床使用；模拟数据、训练数据或内部样本指标不得写成外部泛化能力。

### 9.5 医学决策风险与模型报告

内容要点：

- 区分模型描述、统计推断、预测表现和医学决策：四者不能混写。
- 模型报告最低字段：数据来源、分析表版本、纳入样本量、结局定义、正类定义、预测变量、缺失处理、模型方法、阈值、评价指标、诊断图、限制和需补证据。
- 说明漏判和误判风险：假阴性和假阳性在筛查、诊断、治疗反应预测或药物风险预警中的后果不同，阈值选择需要任务背景。
- 说明模型适用范围：模型表现只对当前数据、当前变量、当前处理流程和当前验证范围负责。
- 说明常见越界表述：相关写成因果，回归系数写成机制，AUC 写成临床可用，准确率写成可靠诊断。
- 给出模型结果表达阶梯：数据中观察到关系；模型支持某种预测或区分；该指标在当前数据中表现如何；医学应用仍需外部验证和专业判断。
- 学习证据：学生能审阅一段模型报告，指出阳性定义缺失、阈值不清、只报准确率、训练集评价越界和医学解释过强等问题。
- 解释边界：没有独立验证、校准评估、临床场景定义、伦理审查或专业指南支持时，不写“可用于临床诊断”“可指导治疗”或“证明机制”。

| 禁止事项 | 不写剂量导致指标变化；不写模型可诊断疾病；不让 AI 猜阳性定义；不只报告准确率；不把 AUC 写成临床有效 |

| 图表 | 目的 | 必备标注 | 不可越界解释 |
| --- | --- | --- | --- |
