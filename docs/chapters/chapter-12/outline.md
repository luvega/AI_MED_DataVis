# 第12章 RNA-seq 数据链条与差异表达分析

## 本章定位

第12章位于第四篇“高维医药数据与 bulk 组学分析”中，承接第11章“高维矩阵、PCA、聚类与热图”，进一步把学生带入 bulk RNA-seq 的分析链条。本章不写成完整命令行生信教程，也不让学生把差异表达表直接解释成机制或临床结论。核心目标是让学生看懂：测序文件如何变成计数矩阵，计数矩阵如何配合 metadata 进入差异表达分析，结果表和图如何被核验和克制解释。

本章面向药学本科生和研究生，默认学生已经理解矩阵、标准化、分组变量、P 值、多重检验、热图和基本图表契约，但尚未系统接触 RNA-seq 分析流程。正文应围绕“先核对数据链条，再核对样本信息，最后解释结果边界”展开。

本章处于第三阶段 Vibe Coding。学生可以让 AI 帮助梳理流程、解释代码、整理差异表达结果表、生成火山图或热图草稿、检查功能富集解释是否越界。但学生必须核验样本来源、分组、批次、重复定义、设计公式、标准化方法、阈值、基因 ID 转换、图表参数和医学解释边界。

课程大纲中第14周和第15周分别覆盖 RNA-seq 基础、表达矩阵理解、差异表达分析和功能解读。因此第12章正文按两个 2 学时单元设计：前半章讲链条和数据结构，后半章讲差异表达结果、图表和解释边界。

## 学习目标与学习证据

1. 学生能解释 RNA-seq 数据从 FASTQ 到 count matrix 的主要节点，并能说明每个节点产生什么文件或表。学习证据是画出流程图并标注输入、处理、输出和人工核验点。
2. 学生能区分 count matrix、标准化表达矩阵和 metadata。学习证据是能检查样本 ID 是否一致、分组是否清楚、批次和重复定义是否可追踪。
3. 学生能说明 RNA-seq 标准化为什么必要，并区分用于差异分析的标准化和用于展示的变换。学习证据是能解释为什么不能直接比较原始 read count。
4. 学生能读懂差异表达结果表中的 gene、log2FoldChange、pvalue、padj 等字段。学习证据是能筛选候选基因并写出不过度解释的结果说明。
5. 学生能审阅火山图、热图和功能富集图的图表契约。学习证据是能指出阈值、标签、输入矩阵、基因集来源、校正方式和越界解释风险。
6. 学生能记录 AI 参与 RNA-seq 结果整理的任务说明、输出摘要、人工修改和核验结论。学习证据是提交 AI 协作记录和需人工确认列表。

| 压力问题 | 本章处理 |

## 小节目录

### 12.1 从 FASTQ 到计数矩阵

内容要点：

- 首次解释 FASTQ：保存测序 reads 及质量信息的文本格式。本章只要求理解它是 RNA-seq 原始序列数据的常见形态，不要求学生手工解析完整文件。
- 说明从 reads 到基因计数的链条：原始 reads 经过质量检查、过滤或修剪、比对或转录本定量、基因注释汇总，最终形成以基因和样本为维度的计数矩阵。
- 区分 raw reads、aligned reads、transcript abundance 和 gene-level count。具体软件和参数待读素材后确定。
- 说明计数矩阵的行列含义：行通常是基因或转录本，列通常是样本，单元格是该样本中分配到该特征的 read count。
- 给出流程核验点：样本命名、参考基因组或转录本集版本、注释版本、测序批次、读段数量、低质量样本、文件是否和 metadata 对得上。
- 学习证据：学生能画出 FASTQ 到 count matrix 的流程图，并标出每一步的输入、输出和需人工确认内容。
- 解释边界：本章不把流程跑通等同于数据可靠，也不把低层软件参数讲成学生必须完全掌握的内容。

### 12.2 count matrix、metadata 与实验设计

内容要点：

- 首次解释 count matrix：RNA-seq 中以基因和样本为维度的原始计数表。它是差异表达分析的核心输入之一。
- 首次解释 metadata：描述样本属性的表，通常包括 sample_id、group、batch、time、sex、treatment、replicate 等字段。
- 说明 count matrix 与 metadata 的匹配关系：矩阵列名必须能与 metadata 的样本 ID 对齐，分组变量和批次变量必须有清楚来源。
- 解释实验设计在差异表达中的作用：比较不是“两个文件相减”，而是在样本、分组、重复和协变量定义清楚后建立设计公式。
- 区分 biological replicate 和 technical replicate。若材料不足或设计不明，应标 `需人工确认`。
- 说明批次混杂风险：如果所有病例都来自一个批次，所有对照都来自另一个批次，差异表达结果可能混入批次差异。
- 学习证据：学生能检查一个 count matrix 和 metadata 是否匹配，并写出比较目标、分组变量、潜在批次和重复定义。
- 解释边界：没有清楚实验设计时，不应让 AI 自动决定差异表达比较。

### 12.3 RNA-seq 标准化思想

内容要点：

- 解释为什么原始 count 不能直接跨样本比较：样本之间测序深度、文库组成和基因表达总体分布可能不同。
- 首次解释 normalization：在本章中指降低测序深度、尺度或组成差异对表达比较的影响。它不同于第11章中减均值除标准差的 standardization。
- 区分几类常见量：raw count 用于建模输入，标准化 count 或变换后表达量用于检查和可视化，TPM/FPKM 等量用于表达量展示时需说明边界。具体口径待读素材后核对。
- 说明标准化前后要检查什么：样本总 count、低表达基因过滤、样本间分布、PCA 或距离图、是否存在异常样本。
- 说明差异分析中的标准化通常由专门软件在模型内部处理，不应把展示用的 log 转换矩阵随意拿来做所有检验。
- 学习证据：学生能解释为什么两个样本中同一基因的 raw count 不能直接当作表达差异结论。
- 解释边界：标准化不能修复错误分组、严重批次混杂、样本污染或实验设计缺陷。

### 12.4 差异表达结果表

内容要点：

- 首次解释 differential expression：比较预先定义的样本组后，筛选在转录水平上显示统计差异的基因或转录本。
- 结果表字段建议包括 gene_id、gene_symbol、baseMean 或平均表达、log2FoldChange、标准误或统计量、pvalue、padj、方向和备注。
- 解释 log2FoldChange：表示两组表达差异倍数的 log2 表达，正负方向依赖比较顺序，必须写清参考组和比较组。
- 解释 P 值和 adjusted P value/padj：P 值反映单个检验结果，padj 用于多重检验后的错误控制。筛选时不能只看未校正 P 值。
- 说明低表达基因、缺失注释、重复基因名、极端 fold-change 和阈值选择都需要记录。
- 给出结果表整理任务：按阈值筛选、按方向分组、保留完整字段、记录筛选条件，不只复制显著基因名单。
- 学习证据：学生能读懂一张差异表达表，并写出“结果支持什么、不支持什么”的简短说明。
- 解释边界：差异表达不是因果机制，也不是药物靶点或临床标志物的直接证据。

### 12.5 火山图、热图与差异基因展示

内容要点：

- 火山图用于同时展示差异大小和统计显著性。横轴通常是 log2FoldChange，纵轴常用 `-log10(padj)` 或类似显著性指标，具体口径必须在图注中说明。
- 火山图必须说明阈值、颜色、标签规则、比较对象和输入结果表版本。不能只标注最显眼基因而不说明筛选规则。
- 热图用于展示选定基因在样本中的表达模式。必须说明输入矩阵、是否做行标准化、距离度量、聚类方法、颜色含义和样本注释条。
- 区分“差异基因热图”和“全部表达矩阵热图”。前者展示筛选基因的模式，不代表全转录组结构。
- 说明图表源数据、绘图脚本和图表契约应一起保存，便于复核和作业评分。
- 学习证据：学生能为火山图和热图写图表契约，并指出至少三个可能被误读的地方。
- 解释边界：图形展示支持观察和筛选，不支持单个基因机制、样本诊断分型或临床建议。

### 12.6 功能富集与结果解释边界

内容要点：

- 首次解释 functional enrichment：检查差异基因列表是否在某些功能类别、通路或基因集中出现得比预期更多。
- 说明输入不仅是“显著基因名单”，还包括基因 ID 类型、背景基因集、阈值、方向、数据库版本和校正方式。
- 入门区分过度表示分析和排序型基因集分析。正文可根据素材选择 ORA、GSEA 或更基础的解释，不强行展开所有方法。
- 解释富集结果表字段：term、description、gene count、gene ratio、pvalue、padj、gene list 等。具体字段待读素材后确定。
- 说明 GO、KEGG、Reactome 等数据库词条是知识库标签，不等于本实验直接证明该通路被激活。
- 给出解释阶梯：差异基因列表富集于某类功能；该结果与某生物过程相关；是否构成机制解释仍需文献、实验或独立数据验证。
- 学习证据：学生能把“富集结果证明某通路驱动疾病”改写成克制表述，并标出需补证据。
- 解释边界：不把富集词条写成医学因果、临床建议、药物靶点或诊断依据。
