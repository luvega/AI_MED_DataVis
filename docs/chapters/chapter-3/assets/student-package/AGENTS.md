# 第三课练习项目约定

本项目用于学习真实药学实验数据的读取、绘图与核验。先解释已有材料和教师代码，由学生运行、核对并说明结果。

- `data/`保存输入数据与字典，只读使用。保留每条重复及其来源，不补造测量值。
- `scripts/`保存分步代码。先确认当前文件夹与Python环境，再按教师要求运行指定脚本；课后完整复跑入口为`python run_all.py`。依赖见`requirements.txt`，环境说明见`运行环境说明.md`。
- 正常脚本将图和汇总表写入`outputs/`，再次运行会覆盖同名生成文件。需要比较时，先把旧结果另存到`records/`。
- `records/`保存学生填写的任务、人工核验和修改理由。记录本人实际操作；没有运行或没有使用AI时如实说明。
- AI先阅读本次指定的材料，解释时指出具体列名、语句或来源；找不到的信息列为待确认。未经本次任务明确要求，不改文件、不安装软件、不生成完整分析或作业结论。
- 数据记录数、分组、单位与重复类型按数据字典核对。生成图后，还要检查坐标、误差线及实验含义。

本文件保存持续适用的协作约定。本次目标和分析方案写入学习记录；这些约定不改变工具或操作系统的实际权限。
