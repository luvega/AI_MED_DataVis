# 三幅图阅读说明

## 图1：坐标尺度怎样影响观察

![同一数据的两种坐标](outputs/Fig1_A_axis_comparison.png)

两个面板都画出A表36条读数，同值或相近的点可能重叠。横轴是1、2、4、8小时，三个处理以颜色和点形区分。左侧按相同数量差划分纵轴，右侧按相同倍数划分。

未处理组的高值达到十亿量级，药物处理后的部分读数降到百至千量级。在线性轴上，后者挤在底部；对数轴使不同数量级的变化能够同时看见。坐标变化没有改变任何一条数据。右图相同垂直距离代表相同倍数，不代表相同数量差。

读图练习：找到2小时Lolamicin的三个点，再回到表中的6000、18000、51000。解释左图难以分辨这三个点的原因。

## 图2：均值和重复值一起看

![杀菌时间曲线](outputs/Fig2_A_time_kill.png)

**图注：**E. coli BW25113在未处理、Lolamicin 4×MIC和环丙沙星4×MIC条件下的CFU/mL。浅色点表示作者报告的三个生物学重复值；实色点与连线表示算术均值，误差线为SEM（样本标准差/√3）。均值与SEM在原数值上计算，纵轴按对数显示。连线连接观测时间点的均值，不表示连续测量。数据对应Muñoz等Nature 2024，Extended Data Fig. 3a；本图叠加展示源表重复点。

两种处理的早期均值下降，未处理组随时间上升。2小时Lolamicin均值25000 CFU/mL，环丙沙星约75333；4小时两组均值约1233和1100；8小时约1933和683。时间点改变后，均值高低关系也发生变化。因此，“2小时的读数较低”是一项可以核对的观察，“全程都更好”则需要另外的比较标准。

SEM不是每个重复的分散范围。Lolamicin在8小时的三个读数为200、5500、100，均值高于4小时，但三个点并没有整齐地聚在均值附近。不能用这一次均值变化直接宣布细菌已产生耐药，也不能只看误差线重叠与否代替统计检验。

## 图3：先辨认被测信号

![胰岛素竞争结合读数](outputs/Fig3_B_competition.png)

**图注：**NNC2215和人胰岛素在3与20 mM D-glucose条件下的hIR-A竞争结合实验。横轴为未标记配体浓度（M，对数坐标），纵轴为与受体结合的标记胰岛素检测信号（CPM）。浅色点为技术三重复，实色点与误差线为均值±SD。两分子保留各自源表浓度，使用共同显示范围。折线仅连接均值，未进行非线性拟合。数据为Hoeg-Jensen等Nature 2024，Fig. 3a、3b的选定条件；首列浓度依作者表头保留。

增加待测配体浓度后，它可以与标记胰岛素竞争受体结合。标记配体结合减少时，检测到的CPM降低。因此，本实验里的“信号低”需要按竞争关系解释，不能直接写成“待测分子作用弱”。

在NNC2215面板中，两种葡萄糖条件在曲线中段分开，20 mM条件的读数更低；人胰岛素的两条曲线较接近。对照帮助我们检查“提高葡萄糖后，普通胰岛素是否也表现出类似变化”。本图提供局部读数趋势；技术三重复和均值连线不承担独立实验验证、亲和力参数估计或患者低血糖风险评价。

读图练习：任选NNC2215中段的同一浓度，找到3与20 mM的六个读数。用实验原理解释差别，再检查人胰岛素面板；不要按两个面板的第几列比较不同分子。
