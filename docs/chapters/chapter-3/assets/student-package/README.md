# 第三课：从药学问题到可核验的数据分析

本课用两份真实研究数据练习提出任务、读代码、运行和解释图形。主例是Lolamicin的杀菌时间曲线，第二例是葡萄糖响应胰岛素的竞争结合实验。先阅读[实验与数据字典](data/实验与数据字典.md)，把自己的初始问题写入[学习记录](records/学习记录.md)。

## 先读项目约定，再明确任务与方案

本课按“准备材料→明确任务→制定方案→执行检查→解释与修订”推进。先读[AGENTS.md](AGENTS.md)，找到输入、代码、输出和记录的约定，在学习记录中补充一条规则并说明用途。Git由教师演示，学生本课无需安装Git或注册账号。

课堂试读提示：

> 请读取当前学生运行包中的AGENTS.md。指出输入、代码、输出和学习记录的位置，说明允许的协作方式，以及覆盖旧输出前需要做什么。引用对应条目；本轮只读解释，不运行程序、不修改文件。若找不到文件，请报告查找的位置。

将回答与实际文件核对；没有使用AI就直接阅读并如实记录。规则文件保存持续约定，本次要比较什么写入任务说明，选哪些行、怎样分组和画图写入分析方案。运行前先画坐标草图，标出时间、CFU/mL、三个处理及重复点。

## 打开与运行

将整个文件夹解压到自己的课程目录，用WorkBuddy打开这个文件夹。保留`data`和`scripts`的相对位置。第二课已配置的Python环境需要有pandas和matplotlib；本包运行时不联网、不安装软件，不读取包外数据。若缺包，先确认正在使用课程环境，再按教师的环境说明处理。

在终端确认工作目录是这个文件夹，然后按课堂顺序执行：

```powershell
python scripts/01_read.py
python scripts/02_lolamicin.py
python scripts/03_insulin.py
```

每份脚本以`# %%`划分讲解段。在教师说明本段的输入和输出之后再运行整个对应文件；本课不要求配置Notebook或特定编辑器插件。独立运行文件时，辅助模块会根据脚本所在位置寻找数据，终端不在包根目录时也可用脚本绝对路径运行。

课后复跑可执行`python run_all.py`。它依次运行三个正常脚本，生成两张汇总表及三幅图的PNG/SVG。程序将覆盖`outputs/`内同名的生成结果；保留变更证据时，先把旧图另存到`records/`。`data/`只读使用。

## 四项现场任务

1. **读表。** 运行`01_read.py`后，核对A有36条记录、12个处理-时间组合，每组合3个值；找到Lolamicin在2小时的6000、18000、51000。说明“36”数的是什么。
2. **核对计算。** 运行`02_lolamicin.py`，检查`A_summary.csv`中该组均值是否25000。观察图1两个坐标显示的同一数据，再读图2。将脚本中的`Y_SCALE = "log"`改为`"linear"`，保存旧图后运行比较，最后恢复`"log"`并复跑。
3. **定位报错。** 单独运行`python scripts/04_column_error.py`。该文件包含教师预设的列名错误，预计会报错。根据真实列名修改`VALUE_COLUMN`，不要修改数据表。记录真实报错、修改和运行结果。
4. **迁移解释。** 在教师说明竞争结合原理后观察图3。先独立说明CPM下降可能代表什么，再请AI解释你尚不清楚的实验或代码语句。核对回答与方法、字典是否一致。
