# 第11章 高维矩阵、PCA、聚类与热图

## 本章定位

第11章位于第四篇“高维医药数据与 bulk 组学分析”的开头，承接第6章的数据整形、第7章的图表契约、第8章的多重检验风险、第9-10章的模型评价和解释边界。本章把学生从普通二维分析表带入“样本 × 特征”的高维矩阵场景，为第12章 RNA-seq 数据链条、第13章公共数据库与医药大数据智能分析、第14章单细胞降维和聚类打基础。

本章属于全书第三阶段“Vibe Coding 意图驱动协作”的起点。学生可以让 AI 辅助生成较长的数据检查、PCA、聚类和热图代码，但前提是先写清输入矩阵、metadata、分组、标准化、距离、参数、输出和解释边界。AI 不能替代样本来源判断、实验设计判断、组学结果解释或医学证据判断。

本章主线是“分析表或表达矩阵 -> 矩阵检查 -> 标准化与距离 -> PCA -> 聚类 -> 热图 -> 参数敏感性复核”。正文应让学生理解：PCA、聚类和热图主要用于探索高维数据结构、检查样本关系和展示矩阵模式。它们不能单独证明分组差异、疾病机制、治疗效果、细胞类型或临床可用性。

## 人机协作边界

### 本章允许 AI 做什么

- 解释高维矩阵、metadata、标准化、距离度量、PCA、聚类和热图等术语。
- 根据学生提供的真实字段和矩阵方向，生成 Python 或 R 的局部分析代码草稿。
- 帮助整理矩阵检查表、PCA 图表契约、聚类参数卡、热图图注和复核清单。
- 解释代码报错，提醒列名、索引、缺失值、矩阵转置、随机种子和包版本问题。
- 对图注和结果说明做克制表达润色，但不能新增样本量、统计结论、医学机制或临床解释。

### 本章不允许 AI 做什么

- 不让 AI 猜测样本来源、分组定义、批次变量、特征含义或生物学意义。
- 不让 AI 自动决定哪些样本是“异常样本”并删除。
- 不让 AI 把 PCA 分离、聚类分支或热图颜色块写成分组差异已被证明。
- 不让 AI 根据少数高权重特征或少数标签基因直接写机制、靶点或诊断价值。
- 不让 AI 在未记录参数和未运行代码的情况下宣称结果可复现。

### 学生必须完成的核验

- 核对矩阵一行和一列分别代表什么，并检查是否需要转置。
- 核对 metadata 与矩阵样本 ID 是否一一匹配，记录未匹配或重复样本。
- 记录标准化、log 转换、中心化、缩放、缺失处理和特征筛选规则。
- 记录距离度量、聚类方法、k 值、随机种子和绘图参数。
- 对 PCA、聚类和热图写出“图中能支持什么、不能支持什么”。
- 保存代码、图表源数据、图表契约、参数卡、输出图和 AI 协作记录。

## 主张-证据-边界

| 本章主张 | 可写到什么程度 | 边界 |
| --- | --- | --- |
| 高维数据需要先核对矩阵和 metadata | 说明行列方向、样本 ID、特征 ID、分组和批次是后续分析的基础 | 不根据列名猜医学含义 |
| 标准化和距离会影响 PCA、聚类和热图 | 说明参数选择改变数值尺度和相似性定义 | 不写某一种参数永远正确 |
| PCA 用少数主成分概括主要变化方向 | 说明样本在 PC 空间中的相对位置和解释比例 | 不把 PCA 分离写成统计检验证明 |
| 聚类根据相似性组织样本或特征 | 说明聚类方法、距离和 k 值会影响结果 | 聚类编号不等于真实生物类别 |
| 热图展示矩阵模式和注释信息 | 说明颜色、行列、尺度和注释条 | 颜色块不自动支持机制解释 |
| 参数敏感性是高维结果复核的一部分 | 要求记录不同参数下的图形变化和稳定模式 | 稳定模式仍需实验设计、统计和外部证据支持 |

## 逻辑压力测试

| 压力问题 | 本章处理 |
| --- | --- |
| PCA 图中两组点分开，是否能写两组显著不同？ | 不能。PCA 是探索性降维图，分离现象需结合实验设计、统计检验、批次检查和外部证据。 |
| 聚类把样本分成两支，是否说明存在两类患者？ | 不能直接写。聚类结果依赖距离、标准化、特征筛选和样本组成，只能作为待验证分层线索。 |
| 热图中一组基因颜色更高，是否能写通路被激活？ | 不能。热图颜色展示矩阵数值模式，通路活性或机制解释需独立分析和文献或实验支持。 |
| AI 生成完整 PCA 和热图代码，能否直接用于报告？ | 不能。学生需核验矩阵方向、metadata 匹配、参数、随机种子、输出路径和解释边界。 |
| 参数敏感性结果一致，是否就能写医学结论？ | 不能。参数稳定只增强探索性结果可信度，不替代研究设计、统计推断和医学证据。 |

## 小节目录

### 11.1 高维小样本数据的基本结构

内容要点：

- 解释高维小样本数据：特征数远多于样本数，常见于表达矩阵、代谢组、蛋白组、药物筛选特征表和多指标临床数据。
- 区分样本、特征、变量、矩阵、metadata 和分组。首次出现 metadata 时说明它是记录样本来源、分组、批次、时间点等信息的表。
- 讲清“样本 × 特征”和“特征 × 样本”两种方向，要求学生先写矩阵方向，再运行 PCA 或聚类。
- 说明高维小样本中常见风险：样本少、特征多、缺失、批次效应、离群样本、重复测量和分组混杂。
- 解释本章分析目标：探索结构、检查样本关系、发现可疑模式和准备后续分析。
- 学习证据：学生能填写矩阵检查表，列出样本数、特征数、ID 字段、metadata 匹配结果和需人工确认项。
- 解释边界：高维结构图只能支持探索性观察，不支持单独写机制、疗效、诊断价值或临床建议。

### 11.2 矩阵、标准化与距离度量

内容要点：

- 从普通分析表转入矩阵对象，说明矩阵中的所有特征通常需要是可计算的数值。
- 区分 normalization 和 standardization：normalization 在本书常指降低测序深度或尺度差异影响；standardization 常指减均值、除标准差，使变量可比较。
- 介绍 log 转换、中心化、缩放、行标准化和列标准化的入门用途。
- 说明缺失值、零值、极端值和不同单位会影响距离、PCA 和热图。
- 首次解释距离度量：衡量样本或特征差异的规则。入门介绍欧氏距离、曼哈顿距离和相关距离。
- 说明距离选择要服务分析问题：关注绝对数值差异还是变化模式相似。
- 学习证据：学生能写出一张参数记录表，说明标准化方法、距离度量、缺失处理和选择理由。
- 解释边界：参数选择是分析假设的一部分，不记录参数就无法复核结果。

### 11.3 PCA 的计算结果与图形解释

内容要点：

- 首次解释 PCA（principal component analysis）：用新的综合坐标概括高维数据中主要变化方向。
- 说明 PCA 常见输出：scores 表示样本在主成分空间中的坐标；loadings 表示特征对主成分的贡献；explained variance 表示主成分解释的数据变化比例。
- 解释 PCA 图的基本读法：看输入矩阵、标准化、PC1/PC2 解释比例、点的含义、颜色分组、离群点和批次信息。
- 说明 PCA 图不能直接证明组间显著差异，也不能单独判断样本来自不同生物类型。
- 引导学生检查高贡献特征，但不要把单个 loading 高的特征直接写成机制或标志物。
- 学习证据：学生能为 PCA 图写图表契约和图注，说明能解释的观察和不能越界的结论。
- 解释边界：PCA 是探索性降维和质量检查工具，分组解释需要结合实验设计、统计和后续验证。

### 11.4 聚类方法与参数选择

内容要点：

- 首次解释聚类（clustering）：根据相似性把样本或特征组织成若干组，用于探索数据结构。
- 介绍层次聚类：根据距离逐步合并样本或特征，结果常用树状图展示。
- 介绍 k-means：预设 k 值，把样本分配到 k 个簇；结果受 k 值、初始化和随机种子影响。
- 说明距离度量、linkage 方法、特征筛选、标准化和 k 值都会改变聚类结果。
- 区分聚类编号、已知分组和生物学类别。聚类编号只是算法输出，不能直接写成疾病亚型或细胞类型。
- 学习证据：学生能提交聚类参数卡，记录方法、距离、linkage、k 值、随机种子和稳定性观察。
- 解释边界：聚类可提出分层线索，不能替代标签验证、差异分析、外部队列或实验验证。

### 11.5 热图、注释条与尺度说明

内容要点：

- 首次解释热图（heatmap）：用颜色展示矩阵数值模式，常与样本或特征聚类一起使用。
- 说明热图必须写清行和列代表什么，是样本、基因、蛋白、代谢物、药物还是临床指标。
- 解释颜色尺度：颜色表示原始值、log 值、z-score、行标准化值或其他变换值，图注必须说明。
- 说明注释条用于展示分组、批次、时间点、组织来源或其他 metadata 信息。
- 讲清行聚类和列聚类的含义，避免把树状图分支直接写成真实分类。
- 说明标签选择规则：显示哪些基因或特征要有明确规则，不应只挑支持预期解释的标签。
- 学习证据：学生能审阅一张热图，指出行列、颜色、标准化、注释条、聚类方法和解释边界是否完整。
- 解释边界：热图展示模式，不自动支持通路、机制、靶点或临床解释。

### 11.6 参数敏感性与结果复核

内容要点：

- 解释参数敏感性：同一数据在不同标准化、距离、特征筛选、聚类方法或随机种子下，结果可能发生变化。
- 要求学生比较至少两类参数变化，例如标准化前后、欧氏距离与相关距离、不同 linkage 方法或不同 k 值。
- 说明复核不是追求“最好看的图”，而是检查结论是否依赖单一参数设置。
- 建立高维图表复核清单：输入矩阵、metadata、参数、图表契约、图注、导出包和 AI 协作记录。
- 说明随机性来源：k-means 初始化、降维算法和部分特征筛选流程可能需要固定随机种子。
- 学习证据：学生能提交参数敏感性记录，写出稳定观察、变化观察、可能原因和仍需验证事项。
- 解释边界：参数稳定只能支持探索性结果更可靠，不能直接升级为统计、机制或临床结论。
