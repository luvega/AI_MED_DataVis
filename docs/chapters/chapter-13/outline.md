# 第13章 公共数据库、序列数据与医药大数据智能分析

## 本章定位

第13章位于第四篇“高维医药数据与 bulk 组学分析”的末尾，承接第12章“RNA-seq 数据链条与差异表达分析”，把学生从“已经拿到矩阵和结果表”带到“公共数据如何检索、下载、记录、解释和用于后续任务”。本章不写成公共数据库大全，也不写成完整命令行生信教程。核心目标是让学生理解：公共数据库中的数据有来源、编号、许可和引用要求；序列、reads、变异和基因 ID 是不同层次的数据对象；医药 AI 任务必须先定义输入、标签、模型、评价指标和解释边界。

本章面向药学本科生和研究生，默认学生已经理解数据字典、图表契约、统计推断、基础分类模型、RNA-seq 计数矩阵和差异表达结果，但尚未系统接触 GEO、SRA、NCBI、FASTA、FASTQ、VCF、ID 转换、表达谱分类、药物结构数据和虚拟筛选。正文应围绕“先找准数据，再记录来源，再读懂格式，最后限定智能分析结论”展开。

本章处于第三阶段 Vibe Coding。学生可以让 AI 帮助生成检索式、整理 accession、解释文件格式、设计下载记录表、检查 ID 转换和梳理模型评价指标。但学生必须核验数据库来源、数据类型、样本说明、引用要求、下载时间、许可边界、物种和 ID 版本、模型标签、训练/测试划分、性能指标和生物医学解释范围。

课程大纲没有把公共数据库单独设为完整周次，但期末综合项目可使用 GEO/TCGA 等公开数据。本章因此作为第12章 RNA-seq 和第14章单细胞之间的桥接章，也为综合项目提供公共数据检索、来源记录和 AI 协作核验方法。

## 学习目标与学习证据

1. 学生能区分 GEO、SRA、NCBI 等公共数据入口的主要用途，并能把一个医药问题改写成可核验的检索任务。学习证据是提交一张公共数据检索记录卡。
2. 学生能记录公共数据下载和引用信息，包括 accession、数据类型、下载时间、样本说明、许可或引用要求、仍需确认事项。学习证据是提交下载日志和数据来源说明。
3. 学生能解释 FASTA、FASTQ、VCF 的基本结构和用途，并能说明 ID 转换为什么需要物种、数据库和版本信息。学习证据是完成格式识读表和 ID 转换核验清单。
4. 学生能说明序列变异可视化的输入和输出，包括参考基因组、BAM、VCF、IGV 或 UCSC 浏览器等对象。学习证据是画出变异浏览流程并标注不可越界解释。
5. 学生能把表达谱分类、药物结构数据、虚拟筛选和其他医药 AI 任务拆成输入、标签、模型、评价指标和解释边界。学习证据是提交 AI 任务说明书。
6. 学生能比较本地计算、Linux/WSL、云平台、Galaxy 或高性能计算平台在课程项目中的角色。学习证据是写出平台选择理由、性能指标和复现记录。

## 小节目录

### 13.1 GEO、SRA 与 NCBI 数据检索

内容要点：

- 首次解释公共数据库：由研究机构、项目或数据库平台公开保存的数据资源。本章只要求学生会查、会记录、会核验，不要求熟练使用所有数据库 API。
- 区分 GEO、SRA 和 NCBI 的入门用途。GEO 常用于表达谱和功能基因组数据集检索，SRA 常用于测序 reads 检索，NCBI Gene/Nucleotide 等入口可用于基因、转录本和序列信息查找。
- 解释 accession 的意义：数据集、样本、实验或运行记录的数据库编号，是后续下载、引用和复核的核心线索。
- 建议正文使用 GEO 中的 GSE/GSM/GPL、SRA 中的 SRR/SRX/SRP 等作为编号示例，具体编号待读素材阶段核对，不自行编造。
- 建立“问题到检索”的路径：医学或药学问题、关键词、物种、疾病或处理条件、数据类型、平台、样本范围、排除条件。
- 学习证据：学生能提交一张检索记录卡，包含数据库、检索式、accession、数据类型、初步样本说明和需人工确认事项。
- 解释边界：检索到公开数据不等于数据质量可靠，也不等于支持某个医学结论。

### 13.2 数据下载记录、许可与引用

内容要点：

- 说明下载记录为什么是分析的一部分：公共数据会更新、撤回、补充样本或修改注释，缺少记录会导致项目不可复核。
- 下载日志建议字段：数据库、accession、数据页面 URL、下载日期、下载方式、文件名、文件大小或校验信息、数据类型、样本说明、原始论文或提交者、许可或引用要求、仍需确认事项。
- 区分“数据库页面信息”“原始论文信息”“本地下载文件”“后续分析表”。学生不能把这些来源混为一谈。
- 说明引用边界：引用公共数据时通常要引用数据库记录、原始研究或数据提交说明；具体要求需查看数据库页面或官方说明。
- 强调原始材料和下载文件只读：不覆盖原始文件，清洗和分析输出写入课程项目目录。
- 学习证据：学生能为一个公共数据集写出下载日志，并标出哪些字段来自数据库页面、哪些字段仍需人工确认。
- 解释边界：正文阶段如果缺少官方许可或引用来源，应标 `需补证据`，不凭常识写数据库政策。

### 13.3 FASTA、FASTQ、VCF 与 ID 转换

内容要点：

- 首次解释 FASTA：用于保存 DNA、RNA 或蛋白质序列的常见文本格式，通常包含序列标识行和序列内容。本章只要求识别结构和用途。
- 首次解释 FASTQ：用于保存测序 reads 及每个碱基质量分数的常见格式。一个 read 通常由标识符、序列、分隔符和质量分数四行组成。
- 首次解释 VCF：Variant Call Format，用于保存变异位点、参考等位基因、替代等位基因、质量、过滤和样本基因型等信息。
- 区分 FASTA、FASTQ、BAM、VCF 的关系：参考序列、原始 reads、比对结果和变异记录属于不同处理阶段。
- 引入 ID 转换：Ensembl gene ID、gene symbol、NCBI Gene ID 等标识体系不同，转换时要记录物种、数据库版本、转换工具和无法匹配项。
- 说明一对多、多对一和版本号风险。例如同一 gene symbol 可能对应多个历史记录，带版本号的 Ensembl ID 需要谨慎处理。
- 学习证据：学生能完成一个文件格式识读表，并为一组基因 ID 写出转换核验清单。
- 解释边界：ID 转换不是生物学解释，不能因为 symbol 更熟悉就删除无法转换的基因。

### 13.4 序列变异与可视化入门

内容要点：

- 首次解释 sequence variant：相对于参考序列观察到的序列差异。本章只讲入门层面的 SNP、Indel 和 CNV，不进入临床遗传判读。
- 说明变异分析常见链条：reads 质量检查、比对到参考基因组、生成 BAM、调用变异、得到 VCF、浏览器中人工检查。
- 引入 IGV 和 UCSC Genome Browser 的用途：加载参考基因组、BAM、VCF 或自定义 track，观察 reads 覆盖、变异位置和注释背景。
- 说明变异可视化要检查什么：参考版本是否匹配、染色体命名是否一致、reads 覆盖是否足够、候选变异是否被低质量区域影响。
- 结合图表规范说明：变异浏览截图应说明基因组版本、位置、track、文件来源和图中元素含义。
- 学习证据：学生能画出 FASTQ 到 VCF 再到浏览器检查的流程图，并写出至少 3 个不可越界解释。
- 解释边界：可视化支持人工检查，不支持直接写致病性、遗传风险、治疗建议或临床诊断。

### 13.5 表达谱分类、虚拟筛选与医药 AI 任务

内容要点：

- 将医药 AI 任务拆成五个问题：输入是什么、标签是什么、模型学什么、指标如何评价、结果能解释到哪里。
- 表达谱分类示例：输入通常是高维表达矩阵，标签可能是疾病类别、组织类型或处理组。模型可用于分类任务教学，但不能直接写成诊断工具。
- 药物结构数据示例：PubChem、SMILES、分子描述符、分子指纹或分子图可作为药物 AI 的输入形式。正文优先解释 Canonical SMILES 的教学用途。
- 虚拟筛选示例：通过分子对接或模型筛选候选化合物，输出通常是排序、分数或候选列表。该结果只支持进一步实验假设。
- 说明性能指标选择：分类任务可涉及准确率、灵敏度、特异度、AUC、PR-AUC、F1、校准等；具体指标取决于样本分布和任务风险。
- 引入数据泄漏和外部验证：公共数据建模必须记录训练/测试划分、特征选择位置、重复样本、批次和外部数据验证情况。
- 学习证据：学生能为一个表达谱分类或虚拟筛选任务写 AI 任务说明书，包含目标、上下文、约束、验证和输出。
- 解释边界：表达谱分类不等于临床诊断；模型解释图不等于机制；docking 不等于结合强度；预测候选不等于药效。

### 13.6 计算平台、性能指标与应用边界

内容要点：

- 说明为什么平台选择会影响项目：公共数据、序列文件和组学矩阵可能带来存储、内存、运行时间、网络下载和软件依赖问题。
- 比较课程常见平台：本地电脑适合小表和图表练习，WSL/Linux 适合命令行生信入门，云平台或 Galaxy 适合流程演示，高性能计算适合大规模批处理。
- 区分计算性能和模型性能。计算性能关注运行时间、内存、存储、I/O、并行效率；模型性能关注预测或分类质量。
- 说明模型性能指标的边界：准确率容易受类别不平衡影响，AUC 不等于临床可用，灵敏度和特异度需要明确阳性定义，校准和外部验证影响实际解释。
- 引入平台复现记录：操作系统、软件版本、包版本、命令参数、输入文件、输出路径、运行时间和错误记录。
- 收束到 AI 协作：AI 可以帮助搭建流程和解释报错，但不能代替学生决定平台、参数、样本排除、指标选择和医学解释。
- 学习证据：学生能为一个公共数据项目写出平台选择说明、性能指标表和复现边界。
- 解释边界：平台跑通不代表方法正确，指标好看不代表模型可用于真实医学决策。
