# 第14章 单细胞转录组数据处理与可视化

## 本章定位

第14章位于第五篇“单细胞、空间组学与综合项目”的开头，承接第11章高维矩阵、PCA、聚类与热图，第12章 RNA-seq 数据链条与差异表达分析，以及第13章公共数据库和序列数据入门。本章把学生从 bulk 表达矩阵带入单细胞转录组场景，重点不是训练完整单细胞分析专家，而是让学生看懂单细胞数据对象、质控、归一化、高变基因、降维、聚类、UMAP、marker 展示和细胞类型注释边界。

本章面向药学本科生和研究生，默认学生已经理解矩阵、metadata、标准化、PCA、聚类、热图、差异表达和图表契约，但尚未系统接触单细胞数据对象和单细胞可视化。正文应围绕“先核对对象结构，再记录过滤和参数，最后限制图形解释”展开。

本章处于第三阶段 Vibe Coding。学生可以让 AI 辅助梳理流程、解释对象结构、生成局部代码、整理参数记录和检查图注，但学生必须核验数据来源、细胞过滤规则、样本与细胞数变化、降维和聚类参数、marker 依据、细胞类型注释来源和医学解释边界。AI 不能把 UMAP 图、聚类编号或 marker 表达直接写成细胞类型、机制、疗效或临床结论。

本章与第15章保持边界：第14章讲单细胞基础处理和可视化；批次整合、条件比较、轨迹分析、RNA velocity、细胞通讯、空间组学、CITE-seq、免疫受体、多模态数据和综合项目交付物留到第15章。

## 逻辑压力测试

| 压力问题 | 本章处理 |
| --- | --- |

## 小节目录

### 14.1 单细胞数据对象与矩阵结构

内容要点：

- 首次解释单细胞转录组测序：在细胞层面记录基因表达，用于观察不同细胞群的表达状态和组成线索。
- 对比 bulk RNA-seq 与 scRNA-seq：bulk 常以样本为列，单细胞常以细胞为基本观察单位。单细胞数据更稀疏，也更依赖 metadata 和过滤记录。
- 解释基因 × 细胞表达矩阵、cell barcode、gene ID、sample_id、batch、cluster、UMAP 坐标等字段。
- 介绍 Seurat object 和 AnnData 的入门含义：它们是保存表达矩阵、细胞注释、基因注释、降维结果和分析结果的对象容器。正文不展开复杂内部结构。
- 说明单细胞对象不是“一个图”，而是矩阵、注释、参数和结果共同构成的分析对象。
- 学习证据：学生能画出单细胞对象结构图，标出矩阵、metadata、降维坐标、聚类编号和 marker 表之间的关系。
- 解释边界：仅凭对象中已有 cluster 或 cell type 字段，不能确认注释一定正确。

### 14.2 质控指标、过滤规则与记录

内容要点：

- 解释质控的目的：识别低质量细胞、低信息细胞、潜在双细胞和异常样本，减少技术噪声对后续图形的影响。
- 介绍常见 QC 指标：每个细胞检测到的基因数、UMI/read count、线粒体基因比例、核糖体基因比例、双细胞评分等。具体指标待读素材后确定。
- 说明过滤规则必须写清阈值、理由、过滤前后细胞数和样本数变化。
- 讲清阈值不是通用常数。不同组织、平台、物种、测序深度和实验目标可能需要不同规则。
- 强调不让 AI 自动决定删除哪些细胞或样本。AI 可提供检查表，但人工必须核验。
- 学习证据：学生能提交质控记录表，列出指标、阈值、过滤数量、保留数量、参数来源和需人工确认项。
- 解释边界：质控过滤不能修复错误实验设计、严重批次混杂或样本标签错误。

### 14.3 归一化、高变基因与降维

内容要点：

- 解释 normalization：在本章中指降低细胞间测序深度、捕获效率或尺度差异对表达比较和可视化的影响。
- 说明单细胞数据常需要在归一化后选择高变基因，作为 PCA 和后续图结构构建的重要输入。
- 解释高变基因：在细胞之间变化较大的基因集合，常用于捕捉细胞状态或细胞群差异线索，但它不是自动的生物学结论。
- 说明 scaling、回归技术变量和 PCA 的入门用途。具体方法和参数待读素材后确定。
- 强调归一化、高变基因数量、PC 数选择会影响邻接图、聚类和 UMAP。
- 学习证据：学生能记录 normalization 方法、高变基因选择规则、PC 数和选择理由。
- 解释边界：归一化和高变基因选择是分析假设的一部分，不能把某个参数设置写成唯一正确答案。

### 14.4 PCA、邻接图、聚类与 UMAP

内容要点：

- 复习 PCA：用少数主成分概括高维表达矩阵中的主要变化方向。
- 首次解释邻接图：根据细胞在降维空间或特征空间中的相似性，把相近细胞连接起来，用于后续聚类或可视化。
- 解释聚类：根据细胞表达相似性把细胞组织成 cluster，cluster 编号只是算法结果。
- 首次解释 UMAP：用于展示高维单细胞数据低维结构的可视化方法。UMAP 中点的位置帮助观察局部和整体结构，但距离不能当作真实空间距离。
- 说明关键参数：高变基因数量、PC 数、邻居数、分辨率、距离度量、随机种子和绘图颜色。
- 学习证据：学生能为一张 UMAP 图写图表契约，说明输入对象、过滤规则、参数、颜色含义、细胞数和解释边界。
- 解释边界：UMAP 分离、聚类分支或颜色块不能单独证明细胞类型、发育轨迹、病理机制或临床意义。

### 14.5 marker 基因展示与细胞类型注释

内容要点：

- 首次解释 marker gene：在特定细胞群中相对高表达、用于辅助注释的基因，不等于绝对专属基因。
- 说明 marker 展示常见图表：feature plot、violin plot、dot plot、heatmap 和 marker 结果表。
- 讲清 marker 解释需要记录表达尺度、比较对象、阈值、基因 ID、数据库或文献依据。
- 说明细胞类型注释是证据整合过程：聚类结果、marker 表达、已知细胞标志、参考数据库、组织背景和人工判断共同支持注释。
- 引入不确定注释：对于依据不足的 cluster，可以写“待注释”“可能为某类细胞”“需人工确认”，不要强行命名。
- 学习证据：学生能整理一张 cluster-marker-annotation 表，列出每个 cluster 的候选 marker、注释依据和不确定项。
- 解释边界：marker 高表达不等于机制成立，也不自动支持疾病因果、药物靶点或临床应用。

### 14.6 单细胞结果的解释边界

内容要点：

- 建立单细胞解释阶梯：数据对象检查、质控过滤、算法输出、图形观察、marker 支持、细胞注释、统计比较、医学解释。
- 区分观察结果、方法来源、允许解释、替代解释和仍需验证内容。
- 说明常见越界表述：把 UMAP 距离当真实发育距离，把 cluster 编号当细胞类型，把 marker 当绝对专属，把细胞比例变化当治疗机制。
- 说明替代解释：批次效应、样本组成差异、组织解离偏倚、双细胞、低质量细胞、参数选择和注释数据库差异。
- 要求学生保存单细胞导出包：对象摘要、过滤记录、参数表、图表契约、关键图、marker 表、注释依据和 AI 协作记录。
- 学习证据：学生能把一段越界单细胞结果说明改写为“观察-方法-允许解释-替代解释-需验证”表。
- 解释边界：单细胞基础分析可以提出细胞组成和表达状态线索，不能单独给出医学因果、临床建议或机制结论。
