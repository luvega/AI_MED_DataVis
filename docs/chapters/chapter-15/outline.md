# 第15章 单细胞进阶、空间组学与综合项目

## 本章定位

第15章位于第五篇“单细胞、空间组学与综合项目”的收束位置，承接第14章“单细胞转录组数据处理与可视化”。第14章主要让学生理解单细胞数据对象、质控、归一化、降维、聚类、UMAP、marker 基因和细胞类型注释；第15章不重复这些基础流程，而是把学生带到更复杂的审阅场景：多样本整合、条件比较、轨迹假设、RNA velocity、细胞通讯、空间转录组、多模态数据和综合项目交付。

本章的核心不是让学生掌握所有进阶算法，而是训练学生审阅分析路线。学生需要说清数据对象是什么、metadata 是否完整、比较目标是否合理、参数和图表是否可复核、结果解释有没有越界。AI 可以辅助搭建流程、整理核验表、生成代码草稿和润色汇报文字，但不能替学生决定批次处理、细胞类型解释、空间区域含义、免疫克隆生物学解释或项目结论。

课程大纲中第17周是综合项目工作坊，第18周是综合项目汇报与课程总结。因此本章后半部分直接服务综合项目：选题、分析路线、交付物、代码复核、图表审阅、AI 协作记录和答辩准备。正文应把前面章节的数据读取、清洗、统计推断、图表契约、建模、RNA-seq 和单细胞基础能力汇总为可评分的项目证据。

## 学习目标与学习证据

1. 学生能解释批次效应、数据整合和条件比较的关系。学习证据是提交一张整合前后核验表，说明 batch、condition、sample、donor 和 cell type 是否混杂。
2. 学生能区分轨迹分析、RNA velocity 和细胞通讯的输入、输出和解释边界。学习证据是把越界解释改写为“观察、方法来源、允许解释、需验证”四栏表。
3. 学生能说明空间转录组数据比普通表达矩阵多出空间坐标或组织图像信息。学习证据是完成空间图表契约，写清 spot/cell、坐标、组织区域和表达尺度。
4. 学生能识别 CITE-seq、免疫受体和多模态数据中的模态、ID 对齐和整合风险。学习证据是画出 RNA、蛋白、TCR/BCR 或空间信息如何与细胞条形码对应。
5. 学生能为综合项目写出选题、数据来源、分析路线、交付物和禁止越界说明。学习证据是提交项目任务说明书、数据字典、图表清单、代码目录和 AI 协作记录。
6. 学生能进行项目汇报前的代码复核和图表审阅。学习证据是用核验清单指出代码、数据、图注、统计和医学解释中的问题，并完成修改记录。

## 逻辑压力测试

| 压力问题 | 本章处理 |
| --- | --- |
| 整合后不同批次混在一起，能否说明整合成功？ | 不能只看混合。还要检查生物分组是否被过度抹平，细胞类型、样本来源和条件信号是否仍可解释。 |
| 轨迹图上有箭头，能否写成真实细胞发育方向？ | 不能。可以写“该模型给出一种顺序或方向假设”，真实过程需时间序列、谱系追踪或独立实验支持。 |
| 配体-受体分析给出高分，能否写成细胞间真实通讯？ | 不能。它通常基于表达和数据库规则，支持候选通讯线索，不等于功能验证。 |
| 空间图上某基因靠近某组织区域，能否写成病理机制？ | 不能。可以描述空间表达模式，机制解释需要组织注释、病理证据和验证实验。 |
| CITE-seq 中蛋白和 RNA 信号一致，能否直接证明细胞类型？ | 不能。可以作为注释依据之一，还需 marker 组合、质控、背景信号和人工审阅。 |
| 综合项目代码跑通，能否说明结论可靠？ | 不能。还要检查数据来源、处理规则、统计前提、图表契约、解释边界和 AI 协作记录。 |

## 小节目录

### 15.1 批次效应、数据整合与条件比较

内容要点：

- 首次解释批次效应：由实验日期、平台、试剂、操作者、样本处理或测序批次引入的非目标差异。本章强调它会影响单细胞嵌入图、聚类和条件比较。
- 区分 batch、condition、sample、donor 和 cell type。学生必须先看 metadata，而不是直接让 AI 判断整合方法。
- 解释数据整合的目的：在多个样本或数据集之间减少技术差异，使相似细胞状态更可比较；同时警惕过度整合把真实条件差异抹平。
- 说明整合前后要检查的图表：按 batch 上色、按 condition 上色、按 sample/donor 上色、按 cell type 上色的 UMAP 或 PCA 图，以及细胞比例和 marker 保留情况。
- 说明条件比较不能把每个细胞都当作独立患者。若研究问题是疾病、药物或处理效应，统计单位和重复定义常需回到 sample 或 donor。
- 学习证据：学生能填写“整合前后诊断表”，指出哪些结果支持继续分析，哪些需要 `需人工确认`。
- 解释边界：整合图好看不等于分析可靠，条件差异也不能自动解释为机制或疗效。

### 15.2 轨迹分析、RNA velocity 与细胞通讯

内容要点：

- 首次解释轨迹分析：根据单细胞表达相似性推断细胞状态的连续变化顺序。本章只要求理解它是模型化排序，不等同于真实时间。
- 首次解释 RNA velocity：利用未剪接和已剪接 RNA 信号估计细胞状态变化方向的模型思路。正文应说明它依赖数据质量和模型假设。
- 首次解释细胞通讯分析：通常基于配体-受体数据库和细胞群表达，提出候选细胞间相互作用线索。
- 区分三类输出：轨迹图给出顺序假设，velocity 图给出方向线索，通讯图给出细胞群之间的候选连接。
- 给出图表审阅点：输入细胞集、起点选择、聚类或细胞类型注释、参数、数据库版本、颜色和箭头含义。
- 学习证据：学生能把“箭头证明细胞分化方向”“高分证明真实通讯”等句子降级为克制表述。
- 解释边界：这些方法不能单独证明发育路径、病程进展、细胞功能或药物作用机制。

### 15.3 空间转录组数据结构与空间可视化

内容要点：

- 首次解释空间转录组：在组织空间位置上测量基因表达，使表达矩阵多出坐标、组织图像或空间区域信息。
- 区分 spot-level、cell-level 和 region-level 数据。不同平台分辨率不同，正文不应默认所有空间数据都能达到单细胞分辨率。
- 说明空间数据对象的关键字段：表达矩阵、metadata、坐标、组织图像、spot/cell ID、区域注释和质控指标。
- 介绍空间可视化的基本形式：组织图像叠加表达、空间点图、空间聚类/区域图、空间差异模式图。具体方法待读素材后选择。
- 给出空间图表契约：必须说明坐标系统、颜色尺度、spot 或细胞定义、组织区域来源、表达是否归一化、图像是否只作背景。
- 学习证据：学生能审阅一张空间表达图，指出图能支持什么、不能支持什么。
- 解释边界：空间共定位和邻近关系不等于因果作用，空间表达模式也不是病理机制证明。

### 15.4 CITE-seq、免疫受体与多模态数据

内容要点：

- 首次解释 CITE-seq：同时测量单细胞 RNA 表达和细胞表面蛋白标签，使 RNA 与蛋白信息通过细胞条形码对齐。
- 首次解释免疫受体数据：TCR/BCR 等免疫受体序列可用于描述克隆型、克隆扩增和免疫细胞关系。本章只讲入门数据结构和解释边界。
- 首次解释多模态数据：同一细胞、同一样本或相邻组织区域中同时获得多类数据，如 RNA、蛋白、ATAC、免疫受体或空间信息。
- 说明多模态整合的核心检查：细胞条形码是否一致、模态是否缺失、抗体背景和噪声如何处理、不同模态的注释是否冲突。
- 展示常见输出：RNA-蛋白对照图、联合嵌入图、克隆型分布表、多模态注释表、模态对齐流程图。
- 学习证据：学生能画出“RNA、蛋白、TCR/BCR 或空间信息如何对齐到细胞或样本”的结构图。
- 解释边界：多模态一致性可增强注释可信度，但不能直接推出免疫机制、治疗响应或临床应用。

### 15.5 综合项目选题、分析路线与交付物

内容要点：

- 将综合项目定位为课程能力整合，不要求学生完成完整科研论文。项目要能展示数据来源、清洗、统计或组学分析、可视化、AI 协作和结果核验。
- 给出选题类型：临床指标数据分析、公开表达矩阵分析、简化 RNA-seq 差异表达、简化单细胞可视化、空间组学图表审阅或医药数据可视化报告。具体选题待读素材和教师要求确认。
- 说明项目路线最低字段：研究或教学问题、数据来源、变量/矩阵说明、metadata、分析步骤、图表计划、核验清单、解释边界。
- 明确交付物：项目说明书、数据字典或 metadata 检查表、核心代码、图表源数据、图表契约、结果说明、AI 协作记录、需补证据清单。
- 加入禁止事项：不改原始数据，不让 AI 猜列名或分组，不写未支持的样本量、统计结论、机制、诊断或临床建议。
- 学习证据：学生能提交一份可审阅项目包，并说明每个文件的用途和复现边界。
- 解释边界：项目报告是课程训练，不自动等同于科研发表证据或临床证据。

### 15.6 项目汇报、代码复核与图表审阅

内容要点：

- 说明项目汇报应围绕问题、数据、方法、图表、结果边界和 AI 协作，而不是只展示最终图片。
- 给出代码复核重点：路径是否相对清楚、原始数据是否只读、包和环境是否记录、随机种子和参数是否保存、输出是否能从头生成。
- 给出图表审阅重点：每张图是否有图表契约、源数据、视觉编码、样本说明、统计信息、图注和不可越界解释。
- 给出结果解释审阅重点：区分观察结果、统计结果、模型输出、医学解释和仍需验证内容。
- 说明 AI 协作记录最低要求：原始任务说明、AI 输出摘要、人工修改、运行或审阅结果、仍需人工确认事项和反思。
- 学习证据：学生能用同一套清单审阅自己或同伴项目，并提交修改记录。
- 解释边界：汇报评分看过程证据和核验质量，不鼓励用无法复现或无法解释的复杂图表制造“高级感”。
