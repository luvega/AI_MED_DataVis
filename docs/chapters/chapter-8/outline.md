# 第8章 统计推断与组间比较

## 本章定位

第8章位于第三篇“图表表达、统计推断与基础建模”中间，承接第6章“数据整形、描述统计与探索性可视化”和第7章“图表契约与科研图表规范”，服务第9章“相关、回归与分类模型”。本章不把统计推断讲成公式推导课，也不让学生机械套用 t 检验。重点是让学生理解：样本统计量会波动，置信区间表达估计不确定性，P 值依赖零假设和检验前提，效应量帮助判断差异大小，多重检验会增加假阳性风险。

本章面向药学本科生和研究生，默认学生已能读入数据、完成分组汇总、绘制基础分布图，但还不熟悉统计检验前提。正文应围绕“比较前先看数据，检验时说明前提，报告时同时写方法、效应量、置信区间和边界”展开。

本章处于第二阶段 Prompt Coding。学生可以让 AI 辅助生成局部 Python 和 R 检验代码、解释报错、整理统计结果表和检查报告语言，但必须亲自核验分组变量、样本量、缺失值、独立性、分布形态、方差假设、配对关系和医学解释边界。

## 学习目标与学习证据

1. 学生能解释抽样误差、标准误和置信区间的关系，并能说明置信区间不是个体取值范围。学习证据是能根据分组汇总表写出均值、SD、SE、95% CI 的含义说明。
2. 学生能用克制语言解释 P 值，区分统计显著、效应大小和实际意义。学习证据是能改写一段“P < 0.05 说明治疗有效”的越界表述。
3. 学生能根据变量类型、分组数量、独立或配对设计、分布和方差情况选择基础组间比较方法。学习证据是能提交方法选择表和前提检查记录。
4. 学生能说明多组比较和多重检验为什么会增加假阳性风险，并能解释调整后 P 值或 FDR 的基本用途。学习证据是能解释为什么不能只挑显著指标汇报。
5. 学生能写出一段不越界的统计结果说明，包含数据对象、方法、样本量、原始单位差异、95% CI、P 值和医学解释边界。

## 小节目录

### 8.1 抽样误差与置信区间

内容要点：

- 解释抽样误差：样本统计量会因抽样而波动，单次样本均值不等于总体均值。
- 首次解释标准误（standard error, SE）：用于描述估计量的不确定性，样本量增加时通常会变小。
- 首次解释置信区间（confidence interval, CI）：用于表达估计值的不确定范围；在本教材中主要用于均值、均值差、比例或模型参数的区间表达。
- 区分标准差、标准误和置信区间：标准差描述样本内个体差异，标准误描述估计量不确定性，置信区间给出参数估计范围。
- 用误差线图或均值差图说明图注必须写清误差线含义，不能把 SD、SE 和 CI 混用。
- 用 ALT/AST 教学模拟数据说明如何计算分组均值、SD、SE 和 95% CI。
- 学习证据：学生能根据一个分组汇总表写出“均值、SD、SE、95% CI”的含义说明。
- 解释边界：置信区间不是“95% 个体都在这个范围内”，也不等于临床可接受范围。

### 8.2 P 值、效应量与实际意义

内容要点：

- 首次解释零假设和备择假设：检验先设定“无差异”或“无关联”的参考模型，再看数据与该模型是否相容。
- 解释 P 值：在零假设和检验前提成立时，观察到当前或更极端结果的概率。
- 说明 P 值不能回答的问题：不能表示零假设为真的概率，不能表示结果可重复的概率，也不能直接表示医学意义。
- 首次解释效应量（effect size）：差异或关联强度的量化指标。本章优先使用原始单位差异和 95% CI；标准化效应量作为补充说明。
- 强调实际意义：药学指标差异要结合单位、测量误差、基线风险、研究设计和专业背景解释。
- 给出结果表达模板：先写数据对象和方法，再写差异方向、原始单位差异、95% CI、P 值，最后写解释边界。
- 学习证据：学生能把“P < 0.05，说明治疗有效”改写为克制统计表述，并标出需补医学证据。
- 解释边界：统计显著不等于医学重要；不显著也不等于完全无差异。

### 8.3 两组比较与方法选择

内容要点：

- 从比较问题出发：结局变量是连续、分类还是等级变量；分组是独立两组还是配对两组。
- 连续变量独立两组：先看分组 n、缺失值、分布、异常值和方差情况，再考虑 Student t 检验、Welch t 检验或非参数检验。
- 连续变量配对两组：先确认同一受试者、同一样本或同一实验单位的前后配对关系，再考虑配对 t 检验或 Wilcoxon 符号秩检验。
- 分类变量两组比较：入门层面说明卡方检验和 Fisher 精确检验的使用场景，重点放在计数表、比例和期望频数检查。
- 强调检验前图表：箱线图、散点叠加箱线图、配对连线图和列联表应先于检验输出。
- Python 和 R 代码均采用教学模拟 ALT/AST 分组比较；代码示例必须显示数据检查、检验调用和结果整理。
- 给出方法选择表：变量类型、组数、是否配对、前提检查、可选方法、报告字段、常见误读。
- 学习证据：学生能为 ALT 在 control/treatment 两组的比较写出检验前检查表和方法选择理由。
- 解释边界：方法选择不能只由 AI 根据列名决定；若研究设计、配对关系或测量单位不清，应标 `需人工确认`。

### 8.4 多组比较与多重检验

内容要点：

- 解释多组比较：三组及以上比较不能简单做多次两两 t 检验，否则会增加假阳性。
- 入门说明 ANOVA：用于比较多个组的均值差异，前提包括独立性、近似正态、方差齐性等；若前提不满足，可考虑 Kruskal-Wallis 等非参数方法。
- 解释事后比较：整体检验提示组间存在差异后，才进一步看哪些组之间不同，并记录校正方法。
- 首次解释多重检验：同时做很多检验时，即使每个检验都使用 0.05 阈值，也更容易出现偶然显著。
- 首次解释调整后 P 值和 FDR：调整后 P 值用于多重检验后的错误控制；FDR 更常见于高维筛选和差异表达结果。
- 用组学素材作为边界案例：差异表达结果常同时报告 log2 fold-change 和 adjusted P value，但本章只讲为什么要校正，不展开 RNA-seq 建模流程。
- Python 和 R 代码可展示 `multipletests` 或 `p.adjust` 的基础用法，重点解释输入是一组 P 值，输出是校正后的结果。
- 学习证据：学生能解释为什么“20 个指标逐个做 t 检验并只挑 P < 0.05 的结果汇报”存在风险。
- 解释边界：多重检验校正降低假阳性风险，但不能修复错误分组、伪重复、批次混杂或数据泄漏。

### 8.5 统计结论的医学解释边界

内容要点：

- 区分观察结果、统计检验结果、统计推断和医学解释：四者不能混写。
- 统计结论报告最低字段：数据来源、分析表版本、纳入样本量、分组定义、方法、检验前提、原始单位差异、95% CI、P 值或调整后 P 值、缺失处理和解释边界。
- 说明独立性和重复定义：同一患者多个样本、同一动物多个切片、同一培养批次多个孔不能简单当作完全独立样本。
- 说明小样本风险：小样本下置信区间宽、检验功效不足，不能把“不显著”写成“无差异”。
- 说明选择性报告风险：只汇报显著结果、隐藏未显著比较或事后改假设会削弱可信度。
- 给出医学解释阶梯：数据中观察到差异；统计上支持存在差异；可能具有实践意义；需要进一步研究验证。正文中必须按证据强度选择动词。
- 学习证据：学生能审阅一段统计结论，指出 P 值误读、效应量缺失、样本独立性不清和医学越界表达。
- 解释边界：没有随机化、盲法、混杂控制、外部验证或机制实验时，不写疗效、因果、机制或临床建议。
