# 猜糖豆记录：数据质量任务

素材ID：THU-DA-L02-C01-A02。用于第5章。任务问题是“哪些记录现在能以同一单位保存为数值，哪些需要回查”，不是估计糖豆总数或检验群体智慧。

## 来源、许可与处理边界

清华《数据分析引论》第2讲的原活动先展示糖豆罐，后换透明沙拉碗，再收集一轮估计。第4章正文4.1将这一情境改编为记录设计问题，本章接着练习接收回答后的质量检查。

本目录14行由教材编写过程于2026-09-20独立构造，**不是公开课课堂实测数据，不恢复其样本数、估计值或真值**。混合单位、缺失、近似文本、负值和导出副本等问题均为本书安排，不表示原课堂发生过这些错误。第4章五行表与本表是两个独立教学版本，编号不可合并。

本目录新增数据、代码和据此生成的图形按[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)提供复用；不覆盖课程视频、截图、课件、第三方软件或全书既有材料。本包没有个人信息和真实实验结果，没有设置实际糖豆总数。

## 原始数据字典

| 字段 | 保存类型 | 含义、单位与合法值 | 缺失及核对要求 |
| --- | --- | --- | --- |
| record_id | 文本 | 一次回答的记录号 | 不得缺失；相同号不同内容必须停止 |
| participant_id | 文本 | 虚构参与者编号，同人可多轮 | 不得缺失；不是唯一记录键 |
| round | 原始文本，核验后整数 | 回答轮次，只允许1或2 | 不得猜补 |
| estimate | 原始文本 | 参与者所填估计量，单位另列 | 空白为未记录；只接受明确十进制数，允许小数，转换后须非负 |
| unit | 文本 | 粒或千粒；1千粒=1000粒 | 盒的容量未知，不转换 |

行号从CSV表头之后的第一条记录开始。教学设定：第11条是第10条的**重复导出副本**；其余回答有各自记录号。这个附带说明提供去重依据，不能把规则直接套到其他调查。

## 核验与清洗规则

1. 精确核对五个列名和顺序，检查编号与轮次。缺列、同号冲突、无编号或轮次非法则停止，不擅自修复。
2. 相同记录号且全行相同的已知重复导出只留首次；同一人两轮回答都留。记录14→13，编号人数仍为11。
3. 保留estimate原文；空白、非数值、未知单位、负值分别移入待核查表，不覆盖原文件。这是暂不进入当前数值表，不是永久删除或断言原记录错误。
4. 按定义将千粒换成粒。0是明确填写的数值，不能当作缺失。
5. 超过5000粒标为review_high，仅提醒核查，**不是统计异常值阈值或删除标准**。12000保留在数值表。阈值是本任务人为指定的审查规则。
6. 输出9条可数值化记录、7个参与者编号；“可数值化”不等于测量正确，也不等于适合任何统计模型。

issues.csv中source_row对应原始记录序号；quarantine.csv保留原五列并附reason；clean.csv含estimate_grains（粒）与review_high（TRUE/FALSE）。问题日志先列重复导出，再按原始顺序列其他问题；一行可有多种风险，本练习脚本只按列出的优先次序登记首个阻止数值化的原因，高值另记。

## 文件与运行

- data/guesses_raw.csv：UTF-8权威输入。
- data/guesses_gb18030.csv、data/guesses.xlsx：由同一输入转换生成，用于编码/格式练习；Excel工作表为guesses，字段保留文本。
- python/quality.py、r/quality.R：同一规则的完整脚本，不改原始数据。Python需要pandas和matplotlib；R使用基础包。
- python/check_formats.py、r/check_formats.R：核对三种输入；Excel读取另需openpyxl/readxl。
- expected/：人工逐条推得的关键核验表，不作为脚本输入。
- results/python与results/r：运行生成的表和图。
- figures/：正文引用图，由Python输出复制，不对数值进行手工修改。

在本目录运行：

```powershell
python python/quality.py
Rscript r/quality.R
python python/check_formats.py
Rscript r/check_formats.R
```

Python/R须得到相同记录ID、清洗流向、问题类型和保留标记；数值绝对误差不超过1e-9。图的字体和像素不作跨语言逐点比较，图所使用的数据须相同。无随机过程，故不设随机种子。

R脚本在Windows非UTF-8会话中设置本次会话的UTF-8字符区域，不修改系统配置；读取警告按错误停止。当前机器曾因区域设置不正确只读入第一行，故不能忽略读取警告或只看退出后的图是否存在。完整行数仍需与输入核对。启动时继承环境产生的区域警告可能出现在脚本设置之前，应与实际读取失败区分。
