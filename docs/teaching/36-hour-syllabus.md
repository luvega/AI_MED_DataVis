# 《医药数据处理与可视化》36课时统一融合修订版

## 一、课程基本信息

| 项目 | 内容 |
| --- | --- |
| 课程名称 | 医药数据处理与可视化 |
| 总学时 | 36学时，18个教学单元，每单元2学时（120分钟） |
| 适用对象 | 药学本科生和研究生；不默认具备高级统计、生物信息学或编程基础 |
| 课程形态 | 理论、演示、上机、同伴核验与项目答辩一体化 |
| 贯穿案例 | Bioconductor `airway` bulk RNA-seq 数据；相关、回归和分类使用现有医药表格小案例 |
| 课程主线 | 以AI应用为方法主线，以RNA-seq为贯穿案例，表格、组学和多模态结果进入同一分析框架 |

本课程只有一套必修主线，所有学生执行同构项目流程和评价标准。学生使用预计算矩阵和结果表完成分析，不在36学时内运行FASTQ比对、定量等重型流程。Linux、FASTQ、比对、定量、ATAC-seq和ChIP-seq只在理解数据来源、审计流程和限定证据时进入课堂。

## 二、课程目标

### （一）知识目标

完成课程后，学生能够：

1. 说出医药表格、样本元数据、计数矩阵、高维结果和单细胞矩阵的观察单位、变量方向及常见文件形式。
2. 解释从研究问题、数据读取、质量检查、统计推断、可视化、差异分析到证据综合的基本关系。
3. 解释P值、效应量、FDR、独立实验单位、伪重复、数据泄漏和高维小样本等概念的使用边界。
4. 说明RNA-seq从公共数据库和FASTQ到计数矩阵、差异表达与富集结果的数据链，并区分表达、开放染色质、结合和细胞类型特异性证据。
5. 说出AI协作中任务说明、代码生成、错误诊断、结果核验、证据审查和使用披露的基本要求。

### （二）能力目标

完成课程后，学生能够：

1. 把一个药学问题拆成样本、变量、比较、输出和解释边界，形成可执行的AI任务说明书。
2. 使用Python或R读取并检查表格、metadata、count matrix和结果表，识别缺失、重复、样本错配、矩阵方向及标识符问题。
3. 在AI辅助下生成局部代码，逐行核对对象、列名、参数和输出，并用运行结果、最小测试和错误日志修正代码。
4. 针对统计图、PCA、热图、火山图和基因组轨迹图选择合适编码，生成可复核的作图数据表、脚本和图注。
5. 审查差异表达、富集、分类和多组学结果，区分观察、统计结果、允许解释、替代解释和仍需验证内容。
6. 提交包含数据字典、代码、环境、结果、证据边界和AI协作日志的可复现项目包，并完成答辩。

### （三）情感与价值目标

完成课程后，学生能够：

1. 在作业和项目中主动披露AI参与范围，不把AI输出冒充个人判断或未经核验的事实。
2. 在处理课程材料时遵守隐私、凭据安全、数据许可和图片授权要求。
3. 面对统计显著、组学关联和模型预测时保持克制，主动说明证据层级和不确定性。
4. 在同伴核验中依据数据、代码和记录提出意见，形成可追溯、可复核的协作习惯。

## 六、统一贯穿案例与教学数据

`airway`案例包含8个人气道平滑肌细胞bulk RNA-seq样本，来自4个细胞系，每个细胞系包含地塞米松处理与未处理条件。课程用它讲解metadata、计数矩阵、文库大小、标准化、PCA、热图、差异表达和结果解释。

该案例的解释边界如下：

- 样本来自细胞实验，不能外推为临床疗效。
- 处理相关差异不能单独证明疾病机制或直接调控关系。
- 8个样本适合教学性复核，不用于本课程的相关、回归和分类预测任务。
- 富集结果反映输入基因集合与注释集合的统计关联，不等同于通路被实验证实激活。
- ATAC-seq、ChIP-seq和单细胞结果以证据卡进入课堂；不同样本或不同研究不得直接进行联合机制推断。

3. 上游测序流程以流程图、日志、预计算文件和检查清单教学，不执行受限移交包脚本。
