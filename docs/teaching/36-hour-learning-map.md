# 《医药数据处理与可视化》36课时学生学习地图

## 课程怎么推进

课程共18次、36学时，每次按现行安排使用120分钟。你会先认识课程与AI工作方式，亲手输入Python短程序，再从医药表格进入样本元数据、RNA-seq计数矩阵及高维、单细胞和多组学结果。第四课的AI主要帮助解释已输入的代码和实际报错；熟悉数据与操作后，再逐步使用局部代码生成。我们希望你在这个过程中练习说明数据含义、核对结果，并作出有依据的专业判断。

Python是主要操作语言。第六课用35分钟正式练习R，第七课继续用它处理已经核对过的结果。近期要求是能读懂、运行和局部修改；每次学习一项用途，不要求从空白写出两套完整分析。

| 主线 | 从哪里开始 | 最终到哪里 |
| --- | --- | --- |
| 数据 | 医药表格 | 样本元数据、计数矩阵、高维、单细胞和多组学结果 |
| 分析 | 读取与整理 | 质量检查、统计推断、可视化、差异分析和证据综合 |
| AI协作 | 问题拆解 | 代码核验、错误诊断、证据审查和可复现交付 |

## 每个单元怎样选择案例

不同单元使用适合各自问题的研究材料和数据。你会反复练习提出问题、理解数据、选择方法、核验结果和解释证据，并把这些能力用到新的情境中。

第四至第六课沿用第三课见过的Lolamicin研究：第四课先算三条CFU/mL记录的均值；第五课从六行表读入CSV与Excel，在36行表中按条件筛选，再用同值宽表和来源对照表完成整形、键连接和导出回读；第六课按处理和时间汇总36行。原始数值和来源记录一起保留，方便随时检查。教材第4章继续保留糖豆案例，第4、6章共同支撑这三课的药学练习。

第14、15课进入RNA-seq时，再使用Bioconductor `airway`，集中认识样本说明、计数矩阵、实验设计和差异表达。该数据来自细胞实验，不能据此判断临床疗效，也不能把差异表达直接写成疾病机制。

## 第4、6章怎样与课堂对应

教材章次与课堂课次分别编排，“第4章”和“第四课”各有自己的内容范围。第五课的数据读取与整形由第4、6章共同支撑，按下面的顺序阅读和操作。

| 什么时候读 | 阅读与操作重点 |
|---|---|
| 第四课 | 先跟随4.5的药学练习，从交互算式走到短脚本；回查4.1的类型、4.2的列表和4.3的位置。亲手改错有单独的课堂时间。 |
| 第五课 | 回查4.1、4.3及4.5的类型、字典、数据框、索引、条件和脚本；读5.1、5.4，练习CSV/Excel、路径、编码、字典、类型与单位检查；结合5.5、5.6记录质量问题；在6.1完成melt长宽转换、pivot还原及来源键连接，导出后回读核对。 |
| 第六课 | 学R向量和索引，运行与修改六行表代码；核对来源记录与均值。 |
| 第七、八课及以后 | 随作图与检查任务阅读4.4中的循环、条件和函数；第十二课再在矩阵任务中复用相关内容。 |

第四课前确认Python入口，第六课前确认R入口。具体准备、目录和运行方法见[练习说明](chapter-practice.md#chapter-4)。第四课作业只交一个短脚本、一次真实输出和简短修改说明；同一份练习中的名称错误、括号错误需要自己实际修正。

第五课先完成[第5章读取与质量练习](chapter-practice.md#chapter-5)，再进入[第6章整形与连接练习](chapter-practice.md#chapter-6)。先预测读取和筛选后的形状，再运行核对；转换前在宽表中指出一个值的去向，转换后检查行数与六个数值。来源连接要检查是否全部匹配。导出CSV或Excel后，从文件重新读取，核对字段、单位、记录数和来源，并保留一次条件变化的运行记录。

## 每次AI协作都要留下什么

1. 你要解决的具体问题。
2. 提供给AI的最小必要上下文。
3. AI输出摘要，不复制冗长对话。
4. 你核对过的列名、对象、参数、样本数和结果。
5. 你做出的修改及修改理由。
6. 可运行代码、运行结果和仍需确认事项。

## 统一项目交付包

所有学生提交同构项目包：数据字典、任务说明书、可运行代码、环境记录、主要图表、结果表、证据边界表、AI协作日志和答辩材料。更换数据集并不改变这些要求。
