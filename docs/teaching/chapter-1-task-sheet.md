# 第1章课堂任务单：从药学问题到数据分析问题

## 使用材料

本任务单配套《第1章 医药数据分析导论》。任务设计依据 `大纲.md`、第一章大纲、术语表、图表规范、第一章正文和本章知识结构图。

任务不要求写代码，也不要求完成统计检验。重点是把问题、数据结构、知识节点和证据边界说清楚。

## 任务目标

学生需要提交一页分析问题拆解表、一张证据边界卡、一段 AI 协作记录，并完成知识结构图读图任务。

| 目标 | 学生表现 |
|---|---|
| 定义问题 | 能把宽泛药学问题改写成可分析问题 |
| 识别数据 | 能说明来源、形态、样本单位和权限 |
| 标注结构 | 能指出变量类型、结局、分组、ID、批次和时间 |
| 说明边界 | 能写出当前数据不能回答的问题 |
| 读懂结构图 | 能指出主节点、辅助节点和人工核验要求 |
| 记录 AI 协作 | 能说明 AI 建议如何被人工核验 |

## 课堂输入

学生可从下列情境中选择一个，也可以使用教师提供的入门材料。

| 情境 | 数据形态 | 可用字段示例 | 适合训练 |
|---|---|---|---|
| 药品销售记录 | 行列表格 | 购药时间、药品名称、数量、金额 | 样本单位、变量类型、描述性问题 |
| 临床指标表 | 患者或就诊记录表 | 患者 ID、年龄、用药组、临床检验字段 | 结局、分组、解释边界 |
| 药效实验记录 | 实验记录表 | 处理组、剂量、时间点、重复编号、读数 | 批次、重复、时间点 |
| 公共数据库字段表 | 下载表或网页表 | 数据库名、字段、注释、下载日期 | 来源、许可、字段解释 |
| 组学矩阵 | 样本乘特征矩阵 | 样本 ID、分组、基因表达值、metadata | 高维数据、元数据、图表边界 |
| 文本资料 | 文献摘要或说明书 | 标题、摘要、关键词、年份 | 文本字段、AI 摘要核验 |

## 技术术语速查

| 术语 | 简明解释 | 本任务中怎么用 |
|---|---|---|
| 样本 | 被观察的对象 | 先判断一行代表什么 |
| 观察单位 | 一条记录对应的对象 | 区分患者、交易、检测和细胞 |
| 变量 | 对样本的记录 | 给每列写类型和角色 |
| ID | 用来识别记录或样本的编号 | 用于去重、连接和追踪 |
| 结局 | 最关心的结果变量 | 分析前写清 |
| 分组 | 用来比较的字段 | 说明按什么分组 |
| 临床指标 | 临床检查或检验形成的字段 | 本任务只当作数据字段使用 |
| 元数据 | 解释样本或字段的附加信息 | 组学和公共数据必须保留 |
| 批次 | 数据产生的实验或技术批号 | 不要误当处理组 |
| 证据边界 | 当前数据能说到哪里 | 写出不能回答的问题 |
| 知识结构图 | 展示概念节点和关系的图 | 读图后要人工核验 |

## 示例：从案例到分析问题

下面示例只展示写法，不代表真实医学结论。

| 步骤 | 示例填写 | 边界 |
|---|---|---|
| 原始问题 | 某类降糖药是不是更好 | 过宽，不能直接分析 |
| 当前数据 | 药品销售记录 | 只有销售和时间字段 |
| 样本单位 | 一条购药记录 | 不是患者疗效记录 |
| 结局变量 | 销售金额或销售数量 | 只能描述销售 |
| 分组变量 | 药品类别或月份 | 分类来源需确认 |
| 可分析问题 | 按月份描述某类药品销售数量和金额变化 | 不写疗效判断 |
| 预期产物 | 数据字典、分组汇总表、趋势图说明 | 后续章节再画图 |

## 操作步骤

### 第一步：写出原始问题

用一句话写出你最初关心的问题。句子可以不成熟，但要保留原样，便于比较修订过程。

|---|---|

### 第四步：判断任务类型

任务类型会限制结论写法。描述、比较、关联、预测和机制探索不能混用。

| 任务类型 | 你要回答什么 | 本任务允许写法 |
|---|---|---|
| 描述 | 数据现状如何 | 描述分布、数量、趋势 |
| 比较 | 不同组是否不同 | 说明比较对象和结局 |
| 关联 | 两个变量是否共同变化 | 写“相关”或“共同变化” |
| 预测 | 能否用已有变量估计结局 | 写预测目标和验证需求 |
| 机制探索 | 可能涉及什么过程 | 写成假设或需验证问题 |

## 评分量表

| 维度 | 合格表现 | 需修改表现 |
|---|---|---|
| 问题定义 | 问题可被数据回答，范围清楚 | 问题过宽或无法对应数据 |
| 数据识别 | 来源、形态、权限和字段说明清楚 | 来源不明或字段解释缺失 |
| 变量标注 | 样本、结局、分组和协变量区分清楚 | 把 ID、批次或时间误当普通变量 |
| 任务类型 | 能区分描述、比较、关联、预测和机制探索 | 把多类任务混成一句话 |
| 证据边界 | 写出不能回答的问题和替代解释 | 把相关、预测或图形模式写成因果 |
| 结构图读图 | 能用正文核验 AI 图 | 直接相信图片标签 |
| AI 记录 | 有提示词、采纳和人工核验 | 只复制 AI 输出 |
