# 《医药数据处理与可视化》统一综合项目模板

## 一、项目原则

全体学生执行同一套流程和评价标准。默认使用airway教学数据包；经教师同意可更换数据集，但不得删去来源核验、数据字典、代码复跑、统计检查、图表契约、证据边界和AI使用披露。

项目结论可以有限，交付证据必须完整。只提交AI生成代码、图片或文字报告，均不构成完整项目。

## 九、答辩准备

每组至少准备回答：

1. 数据从哪里来，当前文件如何确认完整？
2. 一行、一列和独立实验单位分别是什么？
3. AI生成代码中发现过什么错误，怎样证明已经修正？
4. 为什么选择当前统计方法、阈值和图？
5. 最强结论是什么，哪一句话仍然不能说？
6. 其他人如何复跑一项主要结果？

## 十一、提交前检查

- [ ] README给出从环境到结果的最短复跑路径。
- [ ] 原始或来源文件未被覆盖，受限数据未进入公开包。
- [ ] 数据字典、样本顺序、单位和标识符已核对。
- [ ] 代码无硬编码凭据、内网地址和个人本机路径。
- [ ] 主要结果能由脚本重新生成。
- [ ] 图表有作图数据、脚本、图注和解释边界。
- [ ] 统计结果没有被改写成未支持的医学因果或临床建议。
- [ ] AI参与和人工修改已披露。
- [ ] SHA-256清单与最终文件一致。
- [ ] 答辩后勘误记录已纳入最终包。
