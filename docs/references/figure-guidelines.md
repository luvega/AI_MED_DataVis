## 总原则

图表先服务问题，再服务美观。每张图只回答一个主要问题。

图中能支持什么，就解释什么。不要把可视化模式写成因果机制、临床结论或通路证据。

每张正式图都要能追溯到作图数据表、脚本、图表设计规范卡和导出文件。

## 图表设计流程

```mermaid
flowchart LR
  A["研究或教学问题"] --> B["图表设计规范卡"]
  B --> C["作图数据表"]
  C --> D["绘图代码"]
  D --> E["图注与统计说明"]
  E --> F["人工核验"]
  F --> G["可复现图表包"]
```

## 图表设计规范卡

每张正式图在作图前填写。

| 字段 | 填写要求 |
| --- | --- |
| 图表问题 | 一句话说明图让读者观察什么 |
| 数据 | 文件名、表名、字段名、纳入规则、n、缺失和重复定义 |
| 编码 | 图表类型及 x、y、颜色、形状、大小、子图或分面 |
| 图注 | 对象、单位、统计或尺度、缩写和解释边界 |
| 导出 | 作图数据表、脚本、SVG/PDF、PNG、环境和核验记录 |

## 常用图表规范

| 图表 | 适用问题 | 必备标注 | 常见风险 |
| --- | --- | --- | --- |
| 数据字典表 | 变量含义、单位、类型和取值范围 | 变量名、中文名、类型、单位、缺失含义 | 用列名猜医学含义 |
| 缺失值图 | 哪些变量或样本缺失较多 | 缺失比例、变量排序、样本范围 | 把缺失当随机缺失 |
| 直方图 | 连续变量分布 | 变量单位、bin 宽度或数量、n | bin 设置改变读者判断 |
| 箱线图 | 分组分布差异 | 分组 n、箱线含义、异常点定义 | 只看中位数不看分布 |
| 小提琴图 | 分组分布形态 | 密度尺度、分组 n、叠加点或箱线 | 小样本下形态误导 |
| 散点图 | 两个连续变量关系 | 轴单位、相关系数或模型线说明 | 把相关写成因果 |
| 误差线图 | 展示均值和不确定性 | 误差线是 SD、SE 还是 CI | 不说明误差线含义 |
| 残差图 | 回归模型诊断 | 残差定义、拟合值或自变量 | 当作主要结论图 |
| 混淆矩阵 | 分类模型错误类型 | 行列含义、阈值、样本数量 | 只报告准确率 |
| ROC 曲线 | 阈值变化下的区分能力 | AUC、阳性定义、数据集范围 | 写成临床可用阈值 |
| PCA 图 | 高维样本主要变化 | PC 解释比例、输入矩阵、标准化方法 | 写成证明分组差异 |
| 聚类热图 | 样本或基因模式 | 距离、聚类方法、标准化尺度、颜色含义 | 不说明行列尺度 |
| 火山图 | 差异大小和显著性 | log2FoldChange、padj 阈值、基因标签规则 | 挑单个基因过度解释 |
| UMAP | 单细胞低维结构 | 输入对象、降维参数、颜色分组、细胞数 | 把距离当真实生物距离 |
| marker 表达图 | 展示细胞群 marker | marker 名称、表达尺度、细胞群注释依据 | 把 marker 写成绝对专属 |

## 统计信息最低要求

| 场景 | 至少说明 |
| --- | --- |
| 两组比较 | n、中心统计量、离散程度、检验方法、效应量或置信区间 |
| 多组比较 | n、总体检验或多重比较策略、校正方法 |
| 相关分析 | 相关方法、样本量、异常值处理、置信区间或 P 值 |
| 回归模型 | 结局变量、自变量、系数、区间、模型前提或诊断图 |
| 分类模型 | 阳性定义、训练/测试划分、阈值、混淆矩阵、AUC |
| 高维筛选 | 多重检验校正、阈值、输入矩阵、样本分组 |
| 单细胞图 | 过滤规则、细胞数、参数、注释依据 |

## 图注写法

图注应让读者不回正文也能看懂图中对象、编码和统计信息。

| 元素 | 写法 |
| --- | --- |
| 图身份 | 说明图展示的数据对象和任务 |
| 视觉编码 | 说明颜色、形状、线型、子图或分面含义 |
| 样本 | 说明 n、分组和缺失处理 |
| 统计 | 说明检验、误差线、校正和阈值 |
| 缩写 | 首次出现给出解释 |
| 边界 | 对探索性图、模型图和组学图限制解释 |

示例句式：

> 图 X. 不同处理组中 ALT 水平的分布。每个点代表一个样本，箱体表示四分位范围，中线表示中位数。图中仅展示分布差异，组间效应需结合检验结果解释。

## 配色规范

| 场景 | 规则 |
| --- | --- |
| 分组变量 | 同一组在全书使用同一颜色 |
| 连续变量 | 使用单调色带，并标明数值范围 |
| 二分类 | 避免红绿直接对照，优先使用蓝/橙或灰/蓝 |
| 多细胞类型 | 建立配色词汇表，章节内保持稳定 |
| 显著与不显著 | 显著结果可突出，非显著结果不应隐藏 |

## 导出规范

| 文件 | 要求 |
| --- | --- |
| 图片 | 正式图优先导出 PDF 或 SVG；位图至少 300 dpi |
| 作图数据表 | 保存生成图表所需的最小表 |
| 脚本 | 能从源数据重画图，路径不要写死到个人临时目录 |
| 图表设计规范卡 | 与图片同名保存 |
| 环境信息 | 记录 Python/R 版本和关键包版本 |
| 预览图 | 便于快速检查，可另存 PNG |

推荐命名：

```text
fig01_missingness_design.md
fig01_missingness_source.csv
fig01_missingness.py
fig01_missingness.svg
fig01_missingness.png
```

## AI 辅助绘图规则

AI 可以辅助生成代码、解释报错、建议配色和检查图注。

AI 不能替代变量含义判断、医学解释、统计前提判断、结果筛选标准和最终图注审定。

| 场景 | 可让 AI 做 | 必须人工核验 |
| --- | --- | --- |
| 报错排查 | 解释错误信息，给出修改建议 | 修改后代码是否运行，输出是否改变 |
| 图形优化 | 调整标签、主题、图例和导出 | 是否改变数据含义 |
| 统计标注 | 生成检验代码 | 检验前提、分组 n、P 值和校正 |
| 图注润色 | 改写语言 | 是否新增原数据不支持的结论 |
| 组学图 | 整理参数和代码 | 输入矩阵、阈值、基因解释和注释依据 |

## 图表审阅清单

- 图表是否只回答一个主要问题。
- x 轴、y 轴、颜色和图例是否完整。
- 样本量、单位、分组和缺失处理是否可见或可追踪。
- 统计检验、误差线和校正方式是否说明。
- 图注是否区分观察结果和解释推断。
- 作图数据表、脚本、图片和规范卡是否一起保存。
- AI 参与生成或润色时，是否有协作记录和人工核验。
