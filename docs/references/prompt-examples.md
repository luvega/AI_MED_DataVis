## 提示词使用规则

以下样例是课程化改写，不直接移植经济金融案例。使用时替换章节、数据字段、文件路径和作业要求。

每次提交 AI 协作记录时，至少保留任务说明书、AI 输出摘要、人工核验和修改后结果。

## 总模板

来源模式：长任务五项骨架。

适用章节：第2-15章。

```text
目标：
请完成一个明确任务，例如生成清洗计划、检查统计代码、改写图注或审阅章节小节。

上下文：
- 课程章节：
- 学生背景：
- 数据字段：
- 已有代码或图表：
- 必读规则：

约束：
- 不改动原始数据。
- 不新增医学事实、样本量、P 值或文献结论。
- 不能确认时写“需人工确认”。
- 输出要适合药学本科生和研究生入门学习。

验证：
- 说明如何检查代码能否运行。
- 说明统计前提、变量类型和图表编码。
- 指出结论是否超过数据支持范围。

输出：
- 按指定表格或小节输出。
- 给出核验清单。
- 如果涉及文件，说明建议保存路径。
```

必查项：

| 项目 | 检查 |
| --- | --- |
| 目标 | 是否能判断完成 |
| 上下文 | 是否给出数据字段和课程周次 |
| 约束 | 是否写清不能新增事实 |
| 验证 | 是否有运行、统计和解释检查 |
| 输出 | 是否能直接交接 |

## 样例 1：章节小纲生成

来源模式：课程脚本扩写技能中的“学生背景、课堂任务、AI 协作和核验清单”。

适用章节：所有章节。

```text
目标：
请为《医药数据处理与可视化》第6章“数据整形、描述统计与探索性可视化”生成可扩写正文的小纲。

上下文：
- 学生已有 Python/R 基础，但不默认熟悉统计建模。
- 本章承接数据读取和清洗，后接统计推断。
- 本章要覆盖均值、中位数、方差、直方图、箱线图和探索性可视化。

约束：
- 不写高级建模。
- 不新增具体医学结论。
- 每个小节都要有学习证据。

验证：
- 检查小纲是否能支持 2 学时教学。
- 检查是否包含案例任务、图表建议、AI 协作点和核验清单。

输出：
按“学习目标、核心内容、案例任务、图表建议、AI 协作点、常见误区、核验清单”输出。
```

## 样例 2：数据读取报错诊断

来源模式：生成式 AI 辅助数据分析教材中的代码解释和调试任务。

适用章节：第3-5章。

```text

请解释下面 Python 读取 Excel 文件时报错的原因，并给出最小修改方案。

上下文：
- 课程章节：第5章数据读取、数据字典与数据质量。
- 学生刚学 pandas，不熟悉路径和编码。
- 原始数据不能改动。
- 报错信息如下：
[粘贴报错]
- 代码如下：
[粘贴代码]

约束：
- 先解释错误，再给代码。
- 不重写整个脚本。
- 不假设文件内容，无法确认时列为排查步骤。

验证：
- 给出学生能在本机检查的 3 个步骤。
- 说明修改后应看到什么输出。
```

## 样例 3：清洗计划

来源模式：数据清洗章节中“重复、缺失、录入错误、验证”的流程。

适用章节：第5-6章。

```text
- 字段包括：sample_id、group、age、sex、ALT、AST、drug_dose、visit_date。
```

```text
- 代码如下：

- 当前解释如下：
[粘贴解释]

约束：
- 不新增数据中没有的医学结论。
```

## 学生提交时的最小记录

| 字段 | 要求 |
| --- | --- |
| 任务 | 说明这次让 AI 做什么 |
| 原始提示词 | 保留关键版本，不要求贴所有闲聊 |
| AI 输出 | 摘要即可，必要时附关键代码 |
| 核验 | 说明运行、统计、图表和解释检查 |
| 修改 | 写清人工修改了什么 |
| 结果 | 放最终表、图、代码或结论 |
| 反思 | 写清下次会如何改进提示词或核验 |

## airway只读探索与代码核验提示词

```text
目标：
读取 sample_metadata.csv，只描述数据结构并完成输入核验。

已知上下文：
- 文件应包含8个bulk RNA-seq样本。
- 4个cell_line各包含trt和untrt两个样本。
- 真实字段见文件，不得假设存在group列。

约束：
- 只读，不覆盖输入文件。
- 先输出路径、shape、列名和类型，再做唯一性与交叉表检查。
- 不解释药物疗效、疾病机制或临床意义。
- 代码每一步后给出预期检查，不把“未报错”当作验证通过。

验证：
- sample_id为8个且唯一。
- cell_line为4个；cell_line×treatment的8种配对各出现1次。
- 报告缺失、重复和无法确认字段。

输出：
1. 可运行的最小代码；
2. 检查结果表；
3. AI可能误判的位置；
4. 仍需人工确认事项。
```

## 多模态证据卡审阅提示词

```text
目标：
审阅 multimodal_evidence_cards.csv 和给定结果摘要，把每项主张限制在相应证据层级。

上下文：
- 证据可能包括bulk RNA、单细胞RNA、ATAC peak、motif、ChIP信号和空间结果。
- 先检查是否来自同一样本、同一研究以及设计是否兼容。

约束：
- 不把差异表达写成直接调控。
- 不把ATAC peak或motif写成真实结合。
- 不把ChIP信号写成功能因果。
- 不把跨研究共现拼接成同一样本联合机制。
- 证据不足处写“需补证据”或“需人工确认”。

输出表：
| 主张 | 观察结果 | 方法来源 | 允许解释 | 替代解释 | 仍需验证 | 修改后的边界化表述 |
```
